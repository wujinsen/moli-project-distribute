# 订单服务（order-server）

订单业务服务。v1 **真实交付为秒杀子系统**（Redis+Lua + 异步落库），通用订单域为骨架。

| 项 | 值 |
|----|----|
| 服务名 | `order-server` |
| HTTP | **8087** |
| Dubbo | **20882**（Consumer → user-center） |
| 网关 | `/OrderServer/**` |

## 能力摘要

| 部分 | v1 状态 |
|------|---------|
| 秒杀 | ✅ ping / activity / order / metrics / admin/init |
| 通用订单 | 🔴 骨架探针 |

设计见 [[秒杀设计]]；链路图 `docs/diagrams/moli-seckill-flow.drawio`。

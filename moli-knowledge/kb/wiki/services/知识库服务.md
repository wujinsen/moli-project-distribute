# 知识库服务（knowledge-server）

企业知识库的 **Java REST 后端**。与 `kb/`（LLM-Wiki markdown）**双轨**：正文在 wiki 文件，MySQL 为 Sync 只读门面。

| 项 | 值 |
|----|----|
| 服务名 | `knowledge-server` |
| HTTP | **8090** |
| Dubbo | **20884**（Consumer） |
| 网关 | `/KnowledgeServer/**` |

## v1 能力

| 域 | 说明 |
|----|------|
| 浏览/问答/图谱 | `/kb/index` `/kb/page` `/kb/ask` `/kb/graph` |
| Ingest 工作台 | `/kb/ingest/*`（Expert + Express） |
| Wiki 编辑 | `/kb/wiki/page` + AI 改稿 + enrich |
| Wiki 治理 | lint-space + script/ai/auto-fix + merge-hint（**Web T16f 部分**） |
| 三空间 | enterprise-kb · moli-ops-manual · jp-fe-ap-exam |

检索：**MySQL ngram 全文**（M4 ✅）。

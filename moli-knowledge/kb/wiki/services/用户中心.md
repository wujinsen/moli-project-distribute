# 用户中心（user-center-server）

茉莉微服务的**权限中枢**：登录/会话、RBAC、多系统门户，并通过 Dubbo 向 order / bi / knowledge 输出鉴权。

| 项 | 值 |
|----|----|
| 服务名 | `user-center-server` |
| HTTP | **8888** |
| Dubbo | **20881**（`1.0.0` / `moli`） |
| 网关 | `/UserCenter/**` |

## 模块

四子模块：`common`（实体）· `api`（Dubbo 契约）· `server`（主服务）· `shiro-starter`（跨服务校验）。

## 能力摘要

- **认证**：登录/登出，Session 存 Redis，token = sessionId
- **RBAC**：用户/角色/菜单/部门/岗位/字典/动作码
- **门户**：`sys_system` 多系统 enter/switch、SSO Ticket
- **Dubbo**：`getUserById`、`getPermissionsByUserId` 等 3 方法

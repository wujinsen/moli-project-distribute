# 网关（moli-gateway）

基于 **Spring Cloud Gateway** 的统一 API 入口，四路由转发各业务服务。

| 项 | 值 |
|----|----|
| 服务名 | `moli-gateway` |
| HTTP | **21000** |

## 路由（v1）

| 前缀 | 目标 |
|------|------|
| `/UserCenter/**` | user-center-server |
| `/OrderServer/**` | order-server |
| `/BiServer/**` | bi-server |
| `/KnowledgeServer/**` | knowledge-server |

**鉴权在下游 Shiro**，网关仅透传 `Authorization`。

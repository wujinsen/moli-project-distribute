# 网关（moli-gateway）

基于 **Spring Cloud Gateway**（WebFlux 响应式）的统一 API 入口，按路径前缀转发到各业务服务。

| 项 | 值 |
|----|----|
| 服务名 | `moli-gateway` |
| HTTP 端口 | 21000 |

## 路由规则（dev）

| 路由前缀 | 目标服务 | Filter |
|----------|----------|--------|
| `/UserCenter/**` | `lb://user-center-server`（[[用户中心]]） | StripPrefix=1 |
| `/OrderServer/**` | `lb://order-server`（[[订单服务]]） | StripPrefix=1 |
| `/BiServer/**` | `lb://bi-server`（[[bi服务]]） | StripPrefix=1 |
| `/KnowledgeServer/**` | `lb://knowledge-server`（[[知识库服务]]） | StripPrefix=1 |

例：`GET /UserCenter/login` → 去掉 `/UserCenter` → 转发 `GET /login` 到 user-center 某实例。
（`loadtest` profile 只有前 3 条路由，无 knowledge。）

## 重要现状（与文档预期有差）

- **网关不做鉴权**：没有任何 GlobalFilter / Token 校验，鉴权全部在下游各服务的 Shiro 完成。它只透传 `Authorization` 头。见 [[认证与会话机制]]。
- **未接 Sentinel**：网关 POM 没引 Sentinel，无限流/熔断配置（`ARCHITECTURE.md` 仅"建议接入"）。
- **未启用 Nacos 配置中心**（`bootstrap.yml` 的 config 段注释掉了），仅用 Nacos 做服务发现。
- 仅 Nacos Discovery + Ribbon `lb://` 负载均衡 +（loadtest 下）Prometheus 指标。

# 设计模式

> Spring 落地 [[patterns/spring框架中的设计模式]]；IoC/单例 [[spring/spring-ioc与bean生命周期]]；面试 [[patterns/设计模式面试题]]。

GoF 23 种模式分 **创建型 / 结构型 / 行为型**。 Spring Boot 全家桶里，多数日常接触的是 **Spring 容器与 MVC/AOP 的内置实现**，不必手写经典 Gang of Four 代码。

## 1. 三类速览

| 类型 | 意图 | 代表 |
|------|------|------|
| **创建型** | 如何创建对象 | 单例、工厂、建造者 |
| **结构型** | 如何组合类 | 适配器、装饰器、代理 |
| **行为型** | 如何协作 | 策略、模板方法、观察者 |

## 4. 何时手写模式

- 业务复杂分支 → **策略** 替代 if-else
- 多种资源加载 → **工厂** / Spring `@Bean`
- 日志/监控横切 → **代理/AOP**，优先 Spring 而非自写 JDK Proxy

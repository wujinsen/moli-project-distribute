## Q1. 连续子数组的最大和

**题**：整数数组（含负数），求连续子数组最大和。

**示例**：`{1,-2,3,10,-4,7,2,-5}` → **18**（子数组 `3,10,-4,7,2` 或等价段）。

### 思路一：动态规划

`dp[i] = max(dp[i-1] + arr[i], arr[i])`，答案为 `max(dp)`。时间 **O(n)**，空间 O(1) 可滚动。

### 思路二：贪心 / Kadane

维护 `curSum`：若 `curSum < 0` 则清零再累加；全程维护 `maxSum`。

```java
public int maxSubArray(int[] a) {
    if (a == null || a.length == 0) return 0;
    int cur = a[0], max = a[0];
    for (int i = 1; i < a.length; i++) {
        cur = Math.max(a[i], cur + a[i]);
        max = Math.max(max, cur);
    }
    return max;
}
```

### 追问

- 若要求输出子数组起止下标？DP 时记录 start/end。
- 若数组全负数？最大和为**最大单个元素**。

## Q3. 一致性哈希

**场景**：分布式缓存节点扩缩容时，尽量减少 key 迁移。

**要点**：将哈希空间构成环；节点与 key 均哈希落环；顺时针找第一个节点。虚拟节点平衡负载。

## Q4. 反转链表

迭代：`prev=null`，每次 `next=cur.next; cur.next=prev;` 推进。空间 O(1)。

## Q5. 二叉树遍历

前/中/后序递归或栈；层序用队列 BFS。面试常考「中序+前序还原树」。

## Q6. 哈希表原理

数组 + 链表/红黑树解决冲突；负载因子触发 rehash。见 [[java/hashmap-面试题]]。

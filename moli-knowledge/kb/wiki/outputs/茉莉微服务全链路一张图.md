# 茉莉微服务全链路一张图

> **Query crystallize**：综合 [[服务调用与架构]]、[[本地启动指南]]、[[登录与鉴权指南]]、[[认证与会话机制]] 等。细节以各源页为准。

## 1. 逻辑架构

```mermaid
flowchart TB
  Browser[浏览器 / Postman / k6]
  GW[moli-gateway :21000 Netty]
  UC[user-center :8888 Tomcat]
  Order[order-server :8087]
  BI[bi-server :1128]
  KB[knowledge-server :8090]
  Nacos[(Nacos :8848)]
  Redis[(Redis :6379)]
  MySQL[(MySQL moli)]
  Browser --> GW
  GW --> UC
  GW --> Order
  GW --> BI
  GW --> KB
  Order -->|Dubbo| UC
  BI -->|Dubbo| UC
  KB -->|Dubbo| UC
  UC --> Redis
  Order --> Redis
  BI --> Redis
  KB --> Redis
  UC --> MySQL
  Order --> MySQL
  KB --> MySQL
  UC --> Nacos
  Order --> Nacos
  GW --> Nacos
  BI --> Nacos
  KB --> Nacos
```

## 2. 一次登录 + 调订单（Happy Path）

| 步 | 动作 | 技术点 |
|----|------|--------|
| 1 | `POST /UserCenter/login` | 经 [[网关]] StripPrefix → [[用户中心]] |
| 2 | Shiro 校验密码 | SHA-256×15 [[认证与会话机制]] |
| 3 | Session 写 Redis | `shiro:session:login_token_*` |
| 4 | 返回 token | Header `Authorization` [[登录与鉴权指南]] |
| 5 | `GET /OrderServer/order/...` + token | Gateway → [[订单服务]] |
| 6 | Starter 读 Redis Session | 同 database [[茉莉登录与鉴权故障根因汇总]] |
| 7 | Dubbo `getUserById` | [[dubbo-与-nacos]] |
| 8 | `@RequiresPermissions` | RBAC [[rbac-权限模型]] |

## 3. 秒杀热路径（简）

见 [[秒杀全链路与压测要点汇总]]：`/OrderServer/seckill/order` → Redis Lua → 队列 → MySQL。

## 4. 基础设施依赖

| 依赖 | 作用 | 未起症状 |
|------|------|----------|
| Nacos | 注册 + Dubbo | No provider [[故障排查指南]] |
| Redis | Session | 登录 500 / 401 |
| MySQL | 业务数据 | 连接失败 [[数据库初始化指南]] |

## 5. 启动顺序

[[本地启动指南]]：Nacos → MySQL → Redis → user-center → order/bi/knowledge → **gateway 最后**。

## 6. 鉴权边界

- Gateway：**不验 token**，只转发头 [[spring-cloud-gateway]]
- 各业务服务：**Shiro authc** + Dubbo 复核

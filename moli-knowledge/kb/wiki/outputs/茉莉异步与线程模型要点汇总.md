# 茉莉异步与线程模型要点汇总

> **Query crystallize**：Spring MVC 栈下异步、线程、缓存注解与可观测性如何落地。

## 1. 线程模型总览

| 线程来源 | 用途 | 页 |
|----------|------|-----|
| Tomcat HTTP | 同步 API | [[tomcat-连接器调优]] |
| Dubbo/Feign | RPC 客户端/服务端 | [[dubbo-调用原理与分层]] |
| 自定义线程池 | @Async、CF、批处理 | [[spring-async与线程池]] [[线程池-实战调优]] |
| 虚拟线程（可选） | 高并发阻塞 IO | [[java-虚拟线程]] |

**原则**：IO 密集任务**不要**占 Tomcat 线程；**独立命名池** + 拒绝策略 + 监控。

## 2. 异步选型

```
非关键、同进程、可丢 ──▶ @Async（小池）
跨服务、需重试     ──▶ MQ [[rocketmq-架构与实战]]
并行查多源         ──▶ CompletableFuture + 专用池
全链路非阻塞       ──▶ WebFlux（新服务才考虑）[[webflux-响应式入门]]
秒杀核心下单       ──▶ 同步 Redis Lua + 异步落库 [[秒杀设计]]
```

## 3. 上下文与日志

- Shiro `Subject`、MDC `traceId` 依赖 ThreadLocal [[threadlocal-与上下文传递]]
- 线程池 / @Async 必须 **TTL 或 MDC 拷贝** [[transmittable-thread-local跨线程]] [[mdc-日志链路上下文]]
- 生产链路优先 **SkyWalking** [[茉莉可观测性与运维体系汇总]]

## 4. 缓存注解栈

| 层级 | 技术 | 场景 |
|------|------|------|
| L1 | Caffeine | 活动页、字典 [[caffeine-本地缓存实践]] |

## 5. 上线 checklist

- [ ] Gateway 透传 traceId

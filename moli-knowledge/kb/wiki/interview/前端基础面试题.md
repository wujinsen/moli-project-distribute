# 前端基础面试题

与茉莉联调相关的 10 题（含参考答案要点）。

## Q1. 什么是同源策略？

协议、域名、端口三者相同为同源；否则 JS 读跨域响应受限制（img/script 等标签部分例外）。

## Q2. CORS 预检请求是什么？

非简单请求前浏览器发 OPTIONS，服务端返回 Allow-Origin/Methods/Headers；通过后才发真实请求。

## Q3. 开发环境如何优雅避免跨域？

Vue devServer **proxy** 把 API 转到网关/后端，浏览器视角同源。

## Q4. 为什么 Postman 不跨域、浏览器跨域？

同源策略是**浏览器**安全策略；Postman 是 HTTP 客户端，不受限。

## Q5. GET 和 POST 区别？（联调视角）

语义：GET 幂等查询，POST 提交；GET 参数在 URL，POST 可在 body；GET 有长度限制；缓存/书签行为不同。见 [[http与-servlet面试题]]。

## Q6. axios 如何统一带 token？

请求拦截器 `config.headers.Authorization = token`，与 [[登录与鉴权指南]] 一致。

## Q7. Vue 路由 history 模式部署要注意什么？

服务器需 `try_files` 回退 `index.html`，否则刷新子路由 404。

## Q8. JSON.stringify 常见用途？

序列化对象传 API、localStorage 存对象、深拷贝简易版（注意 undefined/function 丢失）。

## Q9. 前后端分离后 Session 怎么处理？

茉莉用 Shiro + Redis **分布式 Session**，前端带 token/Authorization，不单靠 JSESSIONID Cookie 跨域。

## Q10. 网关和业务都配 CORS 会怎样？

可能重复或冲突 header，导致浏览器仍报跨域；**只在一层配置**。见 [[跨域与前后端分离]]。

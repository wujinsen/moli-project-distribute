# 容量规划与水平扩展

> 压测 ；高并发。

## 1. 流程

```
业务预估 QPS → 单实例压测容量 → 冗余系数(1.5~2) → 实例数
 ↓
 瓶颈层：CPU / 线程 / DB / Redis / MQ
```

## 2. 扩展维度

| 层 | 水平扩展 |
|----|----------|
| Gateway / 无状态服务 | 加 Pod + LB |
| Redis | 集群/分片 [[cache/redis-缓存]] |
| MySQL | 读副本 [[mysql-主从读写分离]]；写仍单主 |
| 秒杀 | Redis 前置，DB 异步 |

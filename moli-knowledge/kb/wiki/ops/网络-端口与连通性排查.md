# 网络端口与连通性排查

> 故障树 ；本地启动 ；拓扑。

## 2. 命令速查

```bash
ss -tlnp | grep 8080 # 谁在监听
curl -v http://127.0.0.1:8080/actuator/health
nc -zv 127.0.0.1 6379 # 或 Test-NetConnection (Windows)
docker ps --format '{{.Ports}}'
```

## 3. 典型故障

| 现象 | 原因 |
|------|------|
| Connection refused | 进程未启 / 绑错地址 |
| Timeout | 防火墙 / 安全组 / 网络不通 |
| 间歇失败 | 连接池/ fd 耗尽 [[ops/linux-ulimit与文件句柄]] |

## 4. 跨主机

- Dubbo 注册 IP 非可达网卡 → Nacos 元数据错误 [[middleware/nacos-注册与配置]]
- Docker 容器间用 service name，勿写 localhost

## 5. Windows dev

PowerShell `Test-NetConnection -ComputerName localhost -Port 6379`；与 `moli-knowledge/kb/wiki-moli/develop/docker-compose-茉莉依赖栈.md` 端口映射一致。

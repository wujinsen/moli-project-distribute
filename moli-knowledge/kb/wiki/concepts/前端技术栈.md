# 前端技术栈

管理端采用 **前后端分离**：浏览器 SPA 通过 HTTP 调 或直连后端，鉴权走 `Authorization` 头（见 ）。

## 1. 典型栈

| 层 | 技术 | 说明 |
|----|------|------|
| 框架 | Vue 2.x | 组件化 SPA |
| UI | Element UI | 表单/表格/对话框 |
| 路由 | vue-router | 前端路由 + history/hash |
| 状态 | Vuex（可选） | 登录态、菜单、权限缓存 |
| HTTP | axios | 封装 request 拦截器挂 token |
| 构建 | webpack / vue-cli | `npm run build` → `dist/` |

## 2. 与后端契约

| 项 | 约定 |
|----|----------|
| 入口 | 开发：`localhost:21000` 经 ；生产常经 Nginx 反代 |
| 登录 | POST JSON 或 form，返回 token/sessionId |
| 鉴权头 | `Authorization: <token>`，与 Shiro [[认证与会话机制]] 一致 |
| 响应 | 统一 `MoliResult` 包装（code/msg/data） |

三种常见传参方式（GET query / POST form-urlencoded / POST JSON）见 [[跨域与前后端分离]]。

## 3. 跨域与部署

- **开发**：Vue devServer `proxy` 指网关，或网关配 globalCors（[[spring-cloud-gateway]]）。
- **生产**：Nginx `try_files` 托管 `dist` + `/api` 反代，见 [[nginx反向代理与前端部署指南]]。

## 4. 常见问题

| 现象 | 方向 |
|------|------|
| 浏览器 401、Postman 正常 | token 未挂 / Cookie 域不一致 |
| CORS 报错 | 网关与下游重复 CORS 配置 |
| el-select 选不中 | Element 版本与 `:value` 类型不一致 |

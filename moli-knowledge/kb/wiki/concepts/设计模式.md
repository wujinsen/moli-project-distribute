# 设计模式

> Spring 落地 [[spring框架中的设计模式]]；IoC/单例 [[spring-ioc与bean生命周期]]；面试 [[设计模式面试题]]。

GoF 23 种模式分 **创建型 / 结构型 / 行为型**。茉莉 Spring Boot 全家桶里，多数日常接触的是 **Spring 容器与 MVC/AOP 的内置实现**，不必手写经典 Gang of Four 代码。

## 1. 三类速览

| 类型 | 意图 | 代表 |
|------|------|------|
| **创建型** | 如何创建对象 | 单例、工厂、建造者 |
| **结构型** | 如何组合类 | 适配器、装饰器、代理 |
| **行为型** | 如何协作 | 策略、模板方法、观察者 |

## 2. Spring 中的映射（茉莉触点）

| 模式 | Spring 体现 |
|------|-------------|
| 简单工厂 | `BeanFactory.getBean()` |
| 工厂方法 | `FactoryBean`（如 MyBatis `SqlSessionFactoryBean`） |
| 单例 | 默认 singleton + 三级缓存 [[spring-三级缓存与循环依赖]] |
| 适配器 | `HandlerAdapter` [[spring-mvc请求流程]] |
| 装饰器 | `Wrapper`/`Decorator` 包装流 |
| 代理 | **AOP** CGLIB/JDK 动态代理 |
| 观察者 | `ApplicationEvent` / `ApplicationListener` |
| 策略 | `Resource` 多种实现、`LoadBalance`（Dubbo） |
| 模板方法 | `JdbcTemplate`、`RestTemplate` |

详见 [[spring框架中的设计模式]]。

## 3. 与茉莉架构

| 场景 | 模式思维 |
|------|----------|
| 跨服务鉴权 | Starter **模板方法**式自动配置 [[shiro-starter与跨服务校验]] |
| RPC | Dubbo **代理** + **策略**（负载均衡）[[dubbo-调用原理与分层]] |
| 秒杀 Lua | 非典型 OOP 模式，属**脚本原子**而非设计模式 |
| DCL 单例 | `volatile` + 双重检查 [[volatile与可见性]]（Java 层，非 Spring Bean） |

## 4. 何时手写模式

- 业务复杂分支 → **策略** 替代 if-else
- 多种资源加载 → **工厂** / Spring `@Bean`
- 日志/监控横切 → **代理/AOP**，优先 Spring 而非自写 JDK Proxy

# 延迟消息与队列

> Redis 实现 [[redis-实现延迟队列]]；定时任务 [[xxl-job-分布式定时任务]]。

**延迟消息**：消息投递后 **N 秒/分钟** 才可被消费。场景：

| 场景 | 示例 |
|------|------|
| 订单超时关单 | 30min 未支付自动取消 |
| _retry | 失败后 5min 重试 |
| 提醒 | 预约到期通知 |

## 实现方式对比

| 方式 | 说明 |
|------|------|
| RocketMQ 延迟级别 | 固定 18 档延迟 |
| RabbitMQ DLX+TTL | 死信队列 |
| Redis ZSet | score=执行时间 [[redis-实现延迟队列]] |
| 时间轮 / JDK DelayQueue | 单机 |
| 调度中心 | XXL-Job 扫表 |

秒杀关单可先用 **Redis ZSet + 定时扫** 或 RocketMQ 延迟级别。

# 用户中心产品说明（v1）

> **工程索引**：`docs/product/user-center-requirements.md`  
> **PRD 原文**：`kb/raw/prd/user-center-prd-v1.md`

## 一句话

茉莉 **统一身份 + RBAC + Session 签发** 中心；order/bi/knowledge 通过 Shiro Starter + Dubbo 校验。

## v1 交付

| 域 | 状态 |
|----|------|
| 登录 / Session（Redis） | ✅ |
| RBAC（用户/角色/菜单/部门/动作） | ✅ |
| 多系统门户 enter/switch | ✅ |
| Dubbo 三接口 | ✅ |
| 多租户 / OAuth2 开放平台 | ❌ |

## 验收要点

- ~70 HTTP + 3 Dubbo
- `admin` 超管 `*:*:*`
- 跨服务同 `Authorization` 可访问

# 本地启动指南

面向「我想在本机把茉莉微服务跑起来」的操作指导。

## 1. 环境要求

| 依赖 | 版本建议 |
|------|----------|
| JDK | 1.8 |
| Maven | 3.6+ |
| Nacos Server | 2.0.3 |
| MySQL | 8.0.3 |
| Redis | 5.0.13 |

## 2. 先启动基础设施

1. 启动 **Nacos**（默认 `http://127.0.0.1:8848`，账号/密码 `nacos/nacos`，命名空间 `dev`）。
2. 启动 **MySQL**，建库 `moli`，导入脚本 — 详见 [[数据库初始化指南]]（`scripts/moli.sql` + 秒杀 + 知识库表）。
3. 启动 **Redis**（默认 `6379`）——全服务共享，用于 Shiro 分布式 Session，详见 [[认证与会话机制]]。

> ⚠️ 关键：order / bi / knowledge 与 user-center **必须连同一个 Redis（host/port/password/database 都要一致）**，否则跨服务会话校验失败。

## 3. 修改配置

- Nacos 地址与命名空间：各服务 `bootstrap.yml`
- 数据库 / Redis 连接：各模块 `application-dev.yml`

## 4. 编译

```bash
# 1) 安装父 POM（版本管理）
cd moli-distribute-parent && mvn clean install -DskipTests
# 2) 安装公共模块
cd ../moli-distribute-common && mvn clean install -DskipTests
# 3) 按需编译业务模块
cd ../moli-user-center && mvn clean package -DskipTests
```

## 5. 启动顺序（重要）

按依赖关系依次启动：

1. [[用户中心]]（`user-center-server`，HTTP **8888**）—— 权限中枢，其它服务依赖它鉴权
2. [[订单服务]]（`order-server`，HTTP **8087**）—— 通过 Dubbo 调用用户中心
3. [[bi服务]]（`bi-server`，HTTP **1128**，可选）
4. [[知识库服务]]（`knowledge-server`，HTTP **8090**，可选）
5. [[网关]]（`moli-gateway`，HTTP **21000**）—— 最后启动，统一入口

启动后经网关访问（网关按前缀转发并 StripPrefix=1）：

```
http://localhost:21000/UserCenter/...
http://localhost:21000/OrderServer/...
http://localhost:21000/KnowledgeServer/...
```

## 常见问题定位

- 服务注册不上 → 确认 Nacos 在 `8848`、`bootstrap.yml` 命名空间为 `dev`。
- 登录态/权限异常 → 见 [[认证与会话机制]]，确认各服务 Redis 连接（含 database）一致。
- 怎么登录、怎么带 token 调接口 → 见 [[登录与鉴权指南]]；Swagger 调试见 [[swagger接口调试指南]]。
- **系统性的报错排查** → 见 [[故障排查指南]]（Redis 未启动、Dubbo No provider 等）。
- 前端联调、跨域 → 见 [[前端开发与联调指南]]；容器化依赖 → [[docker部署指南]]。
- **新人 Day-1** → [[茉莉新人上手checklist]]。

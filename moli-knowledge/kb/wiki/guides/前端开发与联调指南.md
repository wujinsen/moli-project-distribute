# 前端开发与联调指南

面向「本地跑前端 + 调茉莉后端」的操作步骤。

## 1. 环境

| 依赖 | 版本建议 |
|------|----------|
| Node.js | 14.x / 16.x LTS |
| npm / yarn | 随 Node |
| 后端 | 按 [[本地启动指南]] 先起 Nacos/MySQL/Redis + 各服务 + [[网关]] |

国内镜像（可选）：

```bash
npm config set registry https://registry.npmmirror.com
```

## 2. 启动前端

```bash
cd <前端项目目录>
npm install
npm run dev    # 或 npm run serve，以 package.json 为准
```

默认 devServer 端口常见 **8080/9528**，与后端 **21000** 不同，需代理或 CORS。

## 3. 联调后端

### 方式 A：devServer 代理（推荐开发）

`vue.config.js` 示例：

```javascript
devServer: {
  proxy: {
    '/UserCenter': { target: 'http://localhost:21000', changeOrigin: true },
    '/OrderServer': { target: 'http://localhost:21000', changeOrigin: true },
    '/KnowledgeServer': { target: 'http://localhost:21000', changeOrigin: true }
  }
}
```

前端请求 `/UserCenter/login/...` 同源发出，由 devServer 转发网关。

### 方式 B：直连网关 + CORS

前端 `baseURL = http://localhost:21000`，网关需配置 `globalcors`（勿与下游服务重复，见 [[跨域与前后端分离]]）。

## 4. 登录与带 token

1. 调登录接口拿 token（见 [[登录与鉴权指南]]）。
2. axios 拦截器：

```javascript
config.headers['Authorization'] = store.getters.token
```

3. 也可用 [[swagger接口调试指南]] 先验证后端再联调页面。

## 5. 构建与部署

```bash
npm run build   # 产出 dist/
```

将 `dist/` 放到 Nginx 静态目录，配置 `try_files` 与 API 反代 — 详见 [[nginx反向代理与前端部署指南]]。

## 6. 常见坑

| 问题 | 处理 |
|------|------|
| `ERESOLVE` 依赖冲突 | `npm install --legacy-peer-deps` 或锁版本 |
| 页面刷新 404 | Nginx 缺 `try_files ... /index.html` |
| 跨域 | 只在一层（网关或 Nginx）解决 |
| 401 仅浏览器 | 检查 Authorization、Redis 会话 [[故障排查指南]] |

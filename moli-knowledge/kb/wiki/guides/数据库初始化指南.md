# 数据库初始化指南

> 启动顺序见 [[本地启动指南]]；压测表与 k6 见 [[秒杀压测指南]]；知识库表与 sync 见 [[wiki同步指南]]。

面向「新环境 / 本机第一次」如何把 **MySQL `moli` 库** 建全。

## 1. 权威数据源

| 文件 | 用途 |
|------|------|
| **`scripts/moli.sql`** | **全库快照**（结构 + 种子数据：用户/角色/菜单等） |
| `docs/sql/02_seckill_schema.sql` | 秒杀表（压测用，全库不含时追加） |
| `docs/sql/03_knowledge_schema.sql` | 知识库表 `kb_*`（[[知识库服务]] 用） |

早期 `docs/sql/00_schema.sql`、`01_baseline_data.sql` 已废弃，**以 `scripts/moli.sql` 为准**。

## 2. Windows 一键导入（推荐）

```powershell
cd D:\work\moli_project\moli-project-distribute
.\scripts\init-db.ps1
```

可选开关：

| 参数 | 效果 |
|------|------|
| `-SkipSeckill` | 不导入秒杀表 |
| `-SkipKnowledge` | 不导入知识库表 |
| `-Password xxx` | 覆盖默认 root 密码 |

脚本顺序：建库 → `moli.sql` → 秒杀 → 知识库 → 打印前 5 个用户。

## 3. 手动导入（CMD）

```cmd
"C:\Program Files\MySQL\MySQL Server 8.0\bin\mysql.exe" -u root -p12345678 -e "CREATE DATABASE IF NOT EXISTS moli DEFAULT CHARSET utf8mb4;"
"C:\Program Files\MySQL\MySQL Server 8.0\bin\mysql.exe" -u root -p12345678 moli < scripts\moli.sql
"C:\Program Files\MySQL\MySQL Server 8.0\bin\mysql.exe" -u root -p12345678 moli < docs\sql\02_seckill_schema.sql
"C:\Program Files\MySQL\MySQL Server 8.0\bin\mysql.exe" -u root -p12345678 moli < docs\sql\03_knowledge_schema.sql
```

Navicat：选中 `moli` → 运行 SQL 文件 → 同上顺序。

## 4. 演示账号与密码

`moli.sql` 含 `zhangsan`、`admin`、`superadmin` 等，**默认密码均为 `123456`**：

- 存储：**SHA-256 + salt `moli`，15 轮**
- `password` 列为 **64 位哈希**，不是明文

若 Navicat 里哈希差一个字符或仍是旧值，登录会失败。一键重置所有演示用户：

```powershell
Get-Content scripts\reset-demo-passwords.sql -Raw | & "C:\Program Files\MySQL\MySQL Server 8.0\bin\mysql.exe" -u root -p12345678 moli
```

登录流程见 [[登录与鉴权指南]]。

## 5. 与各服务的连接

各模块 `application-dev.yml` 典型配置：

```yaml
spring:
  datasource:
    url: jdbc:mysql://127.0.0.1:3306/moli?...
    username: root
    password: 12345678
```

改密码后需**所有服务**对齐。连接池问题见 [[故障排查指南]]。

## 6. 压测与知识库后续步骤

| 场景 | 额外动作 |
|------|----------|
| 秒杀压测 | 确认 `02_seckill_schema.sql` + `load-test/scripts/init-seckill-data.*` |
| 知识库 API | 确认 `03_knowledge_schema.sql` + [[wiki同步指南]] |
| k6 自定义密码 | `k6 run -e LOGIN_PASSWORD=... load-test/k6/...` |

## 7. 常见问题

| 现象 | 处理 |
|------|------|
| 导入报字符集错误 | 库 `utf8mb4`；PowerShell 用 `Get-Content -Encoding UTF8` |
| 登录 500 但 DB 正常 | 多为 **Redis 未启动**，见 [[故障排查指南]] |
| 表已存在冲突 | 新环境 drop 库重建；生产勿直接覆盖 |
| 缺少 kb_ 表 | 补跑 `03_knowledge_schema.sql` |

## 8. 生产注意

- `moli.sql` 含演示数据，**生产应换迁移方案 + 脱敏账号**
- JVM/启停脚本见 [[production-jvm启动参数]]、[[生产环境服务启停脚本]]

# 系统操作手册入口

> **运维向操作文档**已独立为知识空间 **`moli-ops-manual`**（wiki 源 `kb/wiki-ops/`）。  
> 在 Web 端切换空间即可浏览；入口页：**`guides/项目文档总览`**（全 PRD/方案/API/测试/运维索引）。

## 在 Web 端打开

1. 知识库模块 → 空间选择器 → **`moli-ops-manual`（茉莉系统操作手册）**
2. 打开 **`项目文档总览`** 页（slug 在 ops 空间内），或按场景：本地启动、v1 发布、API 契约索引等

## 与 enterprise-kb 的分工

| 空间 | wiki 源 | 内容 |
|------|---------|------|
| **enterprise-kb** | `kb/wiki/` | 技术文章、概念、面试题、知识库治理（Ingest/AI 审校） |
| **moli-ops-manual** | `kb/wiki-ops/` | **guides/** 操作 · **product/** 产品 · **develop/** 技术 · **ops/** 运维 · **test/** 测试 |

## 分类目录（Web 与 markdown 一致）

| 分类 | 目录 | 示例 |
|------|------|------|
| 操作指导 | `guides/` | [[本地启动指南]]（在 ops 空间）、项目文档总览 |
| 产品 | `product/` | 产品需求文档索引 |
| 技术 | `develop/` | API 契约索引、用户中心、网关 |

## 原 slug 对照（请在 ops 空间查找）

以下页面 **不再** 保留在 enterprise-kb 副本，请到 `moli-ops-manual` 空间阅读同名页：

- 操作指南：本地启动、数据库初始化、登录与鉴权、权限管理、故障排查、前端联调、Docker、Nginx、MinIO、Swagger、知识库使用、wiki 同步、查询与体检
- 微服务实体：用户中心、网关、订单服务、BI 服务、知识库服务
- 概念：RBAC 权限模型、认证与会话机制

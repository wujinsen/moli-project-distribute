# 生产环境服务启停脚本

> JVM 参数详解 [[production-jvm启动参数]]；本地 Maven 启动见 [[本地启动指南]]。

摘自经典 **bash `start|stop|restart|status`** 模板，适用于 jar 包部署的 Spring Boot 服务。

## 1. 脚本结构

```bash
#!/bin/bash
JAVA_HOME=/usr/lib/jvm/jdk1.8.0_211
JAVA_OPTS="..."   # 见 [[production-jvm启动参数]]
APP_NAME=my-service-1.0.0-SNAPSHOT.jar
APP_USER=tomcat
SHUTDOWN_WAIT=35
workdir=$(cd $(dirname $0); pwd)
```

核心函数：

| 函数 | 职责 |
|------|------|
| `usage()` | 提示 `start\|stop\|restart\|status` |
| `is_exist()` | `ps -ef \| grep $APP_NAME` 判进程 |
| `start()` | `nohup java $JAVA_OPTS -jar $APP_NAME` |
| `stop()` | `kill` + 等待 `SHUTDOWN_WAIT` 秒 |
| `status()` | 打印 pid |

## 2. 启动要点

```bash
start(){
  is_exist
  if [ $? -eq 0 ]; then
    echo "${APP_NAME} is already running. pid=${pid}"
  else
    cd $workdir
    nohup sudo -u $APP_USER $JAVA_HOME/bin/java $JAVA_OPTS -jar $APP_NAME \
      >> logs/console.log 2>&1 &
    echo "start success"
  fi
}
```

| 实践 | 原因 |
|------|------|
| `nohup ... &` | SSH 断开后进程存活 |
| 独立 `APP_USER` | 非 root 跑 Java |
| `workdir` 固定 | 相对路径 log/config 一致 |
| 重定向 stdout/err | 与 Logback 文件日志互补 |

## 3. 停止与优雅下线

```bash
stop(){
  is_exist
  if [ $? -eq "0" ]; then
    kill $pid
    # 循环等待至 SHUTDOWN_WAIT，超时 kill -9
  else
    echo "${APP_NAME} is not running"
  fi
}
```

- Spring Boot 默认响应 SIGTERM，配合 `server.shutdown=graceful`（2.3+）更稳
- `SHUTDOWN_WAIT` 应大于最长请求处理时间
- 勿直接 `kill -9` 除非超时

## 4. 与茉莉微服务的映射

| 生产脚本思维 | 茉莉本地 |
|--------------|----------|
| 单 jar + 固定端口 | 多模块 `mvn spring-boot:run` / IDE |
| `-Dspring.profiles.active=prod` | `dev` / `loadtest` |
| 统一 `JAVA_OPTS` | 各服务独立 JVM 参数 |
| 先停网关再停业务 | 本地：**先起用户中心，最后起网关**（见 [[本地启动指南]]） |

## 5. 运维检查清单

1. **磁盘**：gc.log、heapdump、console.log 轮转
2. **权限**：jar、日志目录对 `APP_USER` 可写
3. **健康检查**：启动后 curl _actuator 或业务探针（茉莉 dev 无统一 actuator 时需自定）
4. **多实例**：`APP_NAME` grep 需足够独特，避免误杀其它 Java 进程

## 6. Windows 开发机

本仓库 Windows 侧数据库用 `scripts/init-db.ps1`（[[数据库初始化指南]]）；**服务本身仍建议 IDE/Linux 部署脚本**，PowerShell 启停可参考相同状态机逻辑。

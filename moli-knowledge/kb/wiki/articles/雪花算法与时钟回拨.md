# 雪花算法与时钟回拨

> 枢纽 [[分布式id生成]]。

## 1. 64 bit 结构（常见）

```
| 1符号 | 41时间戳(ms) | 10机器ID | 12序列 |
```

- 单机每 ms 4096 个 ID
- **趋势递增**，利于 B+ 树索引 [[b-plus树与-innodb索引结构]]

## 2. 时钟回拨

系统时间被 NTP 调慢 → 可能生成**重复 ID**。

| 处理 | 说明 |
|------|------|
| 抛异常等待 | 简单 |
| 借用未来时间位 | 复杂 |
| 扩展序列号位数 | 降级吞吐 |

## 3. 机器 ID

- datacenterId + workerId（5+5）
- K8s 环境用 StatefulSet 序号或配置中心分配

## 4. vs UUID

订单/流水用雪花；内部关联键可用 UUID（无排序要求时）。

# EverythingClaudeCode：Anthropic Claude Code 配置集合

## 概述
EverythingClaudeCode 是一个由 Anthropic 黑客马拉松获胜者创建的 Claude Code 配置集合。它包含了生产级代理、技能、钩子、命令、规则和 MCP 配置，这些配置经过10多个月的构建和真实产品的密集日常使用而演化。

## 特点
- **生产级配置**：提供了一系列经过实战检验的生产级配置，适用于构建复杂的AI代理。
- **技能与钩子**：包含多种技能和钩子，用于扩展和定制 Claude 的功能。
- **命令与规则**：提供了一系列命令和规则，帮助用户更好地控制和管理 Claude。
- **MCP 配置**：包含多种 MCP（多智能体控制协议）配置，支持多智能体协同工作。

## 使用指南
- **原始代码**：仓库中仅包含原始代码，不包含任何文档或安装指南。
- **详细说明**：指南文件提供了关于如何使用这些配置的详细说明。

## 获取方式
- **GitHub 仓库**：可以通过以下链接访问 EverythingClaudeCode 的 GitHub 仓库：[EverythingClaudeCode](https://github.com/afan-m/everything-claude-code)

## 缺口
- **文档不足**：由于仓库仅包含原始代码，对于不熟悉 Claude Code 的用户来说，可能难以理解和使用这些配置。
- **安装与配置**：指南中未提供详细的安装和配置步骤，可能需要用户自行研究。

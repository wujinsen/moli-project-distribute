# 生产部署拓扑备忘

> ⚠️ **安全**：raw 运维笔记含历史 IP/密码，**不得写入 wiki 明文**。本文只保留拓扑与检查项；凭据请用团队密钥管理（Vault/1Password/运维台账）。

## 1. 典型单机/小规模拓扑

```
[浏览器] → Nginx(80/443) → 静态 dist
                ↓
         Gateway :21000
                ↓
    UserCenter / Order / BI / Knowledge
                ↓
         Nacos · MySQL · Redis · MinIO
```

与 [[服务调用与架构]]、[[茉莉微服务全链路一张图]] 一致。

## 3. 上线检查清单

- [ ] 各服务 `application-pro.yml` 指向生产 Nacos 命名空间
- [ ] **全服务 Redis host/port/db/password 一致**
- [ ] MySQL 已执行 `scripts/moli.sql` + 业务增量脚本
- [ ] Gateway 路由与前端 `baseURL` 前缀一致
- [ ] Nginx `try_files` + API `proxy_pass` 已测
- [ ] 防火墙/安全组放行 80/443（及 SSH 管理口）
- [ ] JVM 参数与日志目录可写

## 4. 启停顺序

与 [[本地启动指南]] 相同：基础设施 → user-center → 业务服务 → gateway → 刷新 Nginx。

## 5. 与压测环境区别

压测使用 `application-loadtest.yml`、专用登录接口等，见 [[秒杀压测指南]]、[[loadtest-profile与压测登录]]，**勿与生产混用**。

# 发布回滚指南

> 配合 [[v1发布Runbook]] 使用

## 1. 何时回滚

- 冒烟 P0 多项失败
- 登录 / 知识库 / 网关 503 不可用
- 数据错误且无法热修

## 2. 应用回滚（首选）

1. 逆序停服：gateway → 业务 → user-center
2. 部署上一稳定 JAR/镜像
3. 正序启动
4. 最小冒烟 G1–G3、K1–K2

Nacos 配置一并回退；**勿同时改 DB**。

## 3. 数据库

v1 增量 SQL **多数无 down**。优先 **只回滚应用**；必要时从发版前备份还原。

## 4. Wiki 回滚

1. Git revert wiki 目录
2. `run_sync.sh dry-run-all` → `sync-all`
3. Web 验证 + [[查询与体检指南]]

## 5. Redis / 秒杀

loadtest 可 `admin/init`；生产清 `moli:seckill:` 前缀；Session 一般让用户重登。

工程原文：`docs/ops/rollback-guide.md`

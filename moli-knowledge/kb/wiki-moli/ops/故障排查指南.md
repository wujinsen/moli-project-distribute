# 故障排查指南

> 启动顺序与环境见 [[本地启动指南]]；登录/token 见 [[登录与鉴权指南]]。

面向茉莉微服务**本地联调与常见生产问题**的快速决策树。登录/鉴权专项对照表见 [[茉莉登录与鉴权故障根因汇总]]。

## 1. 登录 / 鉴权 500 或失败

| 现象 | 优先检查 |
|------|----------|
| 登录 500，日志 Redis 连接 refused | **Redis 未启动**（6379）→ 启动 Redis |
| 登录成功但跨服务 401 | 各服务 **Redis host/port/password/database 不一致** → 对齐 `application-dev.yml` |
| token 无效 | Header 是否为 `Authorization: <sessionId>`，见 [[登录与鉴权指南]] |
| 权限不足 403 | RBAC 角色菜单，见 [[权限管理操作指南]] |

Session 机制见 [[认证与会话机制]]；Redis 角色见 [[茉莉-缓存-多级]]。

## 2. 服务注册 / Dubbo 调用失败

| 现象 | 优先检查 |
|------|----------|
| Nacos 无实例 | Nacos 是否 `8848` 启动；`namespace=dev` |
| Dubbo No provider | [[用户中心]] 是否先启动；`group=moli` `version=1.0.0` 一致 |
| Gateway 404 | 路径前缀 `/UserCenter/` 等是否正确；网关是否最后启动 |

详见 [[茉莉-nacos-dev命名空间]]、[[茉莉-dubbo-group版本]]。

## 3. 数据库相关

| 现象 | 优先检查 |
|------|----------|
| 连接失败 | MySQL 8 是否启动；库名 `moli`；账号密码 |
| 表不存在 | 是否执行 `scripts/moli.sql` + 秒杀/知识库增量 SQL |
| 慢 / 池耗尽 | Druid 连接池配置是否生效；慢 SQL 索引见 `moli-knowledge/kb/wiki/database/mysql-索引.md` |
| 登录用户不存在 | 是否导入 baseline 用户；`reset-demo-passwords.sql` |

## 4. 秒杀 / 订单异常

| 现象 | 优先检查 |
|------|----------|
| 库存不准 | Redis 预热脚本；Lua 脚本是否执行 |
| 订单未落库 | 消费者线程是否运行；Redis 队列积压 |

见 [[秒杀设计]]、[[订单服务]]。

## 5. JVM / 进程

| 现象 | 处理 |
|------|------|
| OOM / Metaspace | `moli-knowledge/kb/wiki/java/jvm-oom与排查入门.md`：jmap dump + MAT |
| CPU 100% | jstack 定位线程；是否 Full GC 死循环 → [[故障排查指南]] |
| 端口占用 | `netstat` / 改 `server.port` |

## 6. 推荐排查顺序

```
1) 基础设施三件套：Nacos + MySQL + Redis 全活
2) user-center 注册成功且 HTTP 8888 可访问
3) 业务服务 + Dubbo 调通
4) Gateway 21000 转发
5) 前端 / Postman 带 token 调接口
```

## 7. 日志位置

各服务控制台 / IDE Run 窗口；生产按部署目录 `logs/`（若有）。开启 `debug: true` 仅临时排查 Spring Boot 自动配置。

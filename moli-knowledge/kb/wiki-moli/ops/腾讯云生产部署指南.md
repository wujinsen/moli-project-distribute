# 腾讯云生产部署指南

> **完整上线（权威）**：``deploy/腾讯云上线流程.md``  
> **仅装基础环境**（JDK/MySQL/Redis/Nginx/Nacos + 自检）：``docs/ops/tencent-cloud-cvm-bootstrap.md``  
> **CVM 登录**：OS 用户 ``ubuntu`` · **MySQL 只用 ``root``** · 库名 ``moli``（三者勿混）  
> **AWS 专版**：``deploy/上线流程.md``（**勿**在腾讯云上执行 `yum`）

面向「从 AWS 迁到腾讯云 CVM」或「新购 Ubuntu 服务器首次上线茉莉 v1 三件套」。

| 场景 | 打开 |
|------|------|

## 2. 与 AWS 版主要差异

| 项 | 腾讯云 | AWS |
|----|--------|-----|
| 包管理 | `apt` | `yum` / `dnf` |
| JDK 11 | OpenJDK / Temurin，`JAVA_HOME` 如 `/usr/lib/jvm/java-11-openjdk-amd64` | Amazon Corretto |
| MySQL | `apt install mysql-server` → **MySQL 8.0**（装完用 `mysql --version` 验证，勿装 MariaDB） | `yum` 对应包 |
| Redis | `apt install redis-server` · `redis-cli ping` → PONG | 同左（Amazon Linux 用 yum） |
| 防火墙 | 安全组 + 可选 UFW | Security Group |
| 系统登录 | **`ubuntu`**（腾讯云 Ubuntu 镜像默认） | `ec2-user` / `ubuntu`（视 AMI） |

业务目录、启停脚本、DB 导入、Wiki Sync、冒烟清单 **与 AWS 相同**：部署根 ``/opt/moli-project-distribute``。

## 3. 基础环境安装顺序（摘要）

1. ``ssh ubuntu@<弹性IP>`` · ``apt update`` · 时区 ``Asia/Shanghai``
2. **JDK 11** → **MySQL 8**（``moli`` utf8mb4 · root 改 ``mysql_native_password``）→ **Nginx** → **Redis** → **Nacos** → **Python3/pymysql**
3. 装完自检（详见 bootstrap 文档 §4）：

```bash
mysql --version    # 8.0.x
redis-cli ping     # PONG
java -version      # 11.x
systemctl is-active mysql redis-server nginx
```

4. 导入 ``scripts/moli.sql`` 或 AWS ``mysqldump`` —— [[数据库初始化指南]]
5. 就位 JAR + ``conf/moli-*.env`` → 启停三服务 → Nginx → Sync → 冒烟

## 4. MySQL 常见坑（Ubuntu 24.04）

| 现象 | 原因 | 处理 |
|------|------|------|
| `ERROR 1698` | 新装 root 默认 ``auth_socket`` | ``sudo mysql`` → ``ALTER USER ... mysql_native_password`` |
| 版本不是 8.0 | 误装 ``mariadb-server`` | 卸载后 ``apt install mysql-server-8.0`` |

完整步骤见 ``docs/ops/tencent-cloud-cvm-bootstrap.md`` §3.2 与 ``deploy/腾讯云上线流程.md`` 附录 A。

## 5. 迁移（AWS → 腾讯云）

1. AWS 上 ``mysqldump`` 备份 ``moli`` 库  
2. 复制三份 ``moli-*.env``（改 ``JAVA_HOME``、内网地址）  
3. 新环境冒烟通过后 **DNS 切流** 到腾讯云弹性 IP  
4. AWS 保留 24–72h 只读 —— [[发布回滚指南]]

## 6. 系统内运维（可选）

登录 Web → **运营管理 → 部署中心**（SSH 启停、上传、远程命令），需 SQL `21`/`22` 与 ``OPS_*`` 配置。见 [[服务器运维模块规划]] · ``docs/api/operation-deploy-api.md``。

# 腾讯云生产部署指南

> **工程正文（权威）**：``deploy/腾讯云上线流程.md``  
> **CVM 登录**：OS 用户 ``ubuntu`` · **MySQL 只用 ``root``** · 库名 ``moli``（三者勿混，见工程正文 §3.2）  
> **AWS 专版**：``deploy/上线流程.md``（Amazon Linux / EC2，**勿**在腾讯云上执行其中的 `yum` 命令）

面向「从 AWS 迁到腾讯云 CVM」或「新购 Ubuntu 服务器首次上线茉莉 v1 三件套」。

## 2. 与 AWS 版主要差异

| 项 | 腾讯云 | AWS |
|----|--------|-----|
| 包管理 | `apt` | `yum` / `dnf` |
| JDK 11 | OpenJDK / Temurin，`JAVA_HOME` 如 `/usr/lib/jvm/java-11-openjdk-amd64` | Amazon Corretto |
| 防火墙 | 安全组 + 可选 UFW | Security Group |
| 系统登录 | **`ubuntu`**（腾讯云 Ubuntu 镜像默认） | `ec2-user` / `ubuntu`（视 AMI） |
| 上传代码 | SCP / SFTP / 云助手 / `git pull`（`ubuntu@<IP>`） | EC2 同左 |

业务目录、启停脚本、DB 导入、Wiki Sync、冒烟清单 **与 AWS 相同**：部署根 ``/opt/moli-project-distribute``。

## 3. 首次安装顺序（摘要）

1. CVM 安全组：公网 **80/443**；**勿**公网开放 3306 / 6379 / 8848 / 21000  
2. 安装 **JDK 11 · MySQL 8 · Nginx · Redis · Nacos**（详见工程正文 §3）  
3. 导入 ``scripts/moli.sql`` 或从 AWS ``mysqldump`` 迁入  
4. 就位 JAR + ``conf/moli-*.env`` + ``application-pro.yml``  
5. ``deploy/linux/moli-service.sh`` 启停三服务  
6. Nginx 反代网关 **21000** + 托管前端 ``dist/`` —— [[nginx反向代理与前端部署指南]]  
7. ``sync-all``（有 wiki 变更时）—— [[wiki同步指南]]  
8. 冒烟：``docs/test/release-smoke-checklist.md``

## 4. 迁移（AWS → 腾讯云）

1. AWS 上 ``mysqldump`` 备份 ``moli`` 库  
2. 复制三份 ``moli-*.env`` 密码与 Nacos/Redis 配置到新 CVM（改 ``JAVA_HOME``、内网地址）  
3. 新环境冒烟通过后 **DNS 切流** 到腾讯云弹性 IP  
4. AWS 实例保留 24–72h 只读以便回滚 —— [[发布回滚指南]]

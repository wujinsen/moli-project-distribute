# 生产 / 预发环境检查表

> 配合 [[v1发布Runbook]] 使用 · 工程原文：`docs/ops/production-checklist.md`

## 1. 基础设施

MySQL 8 utf8mb4 · Redis 6+ · Nacos 2.x 命名空间隔离 · NTP 时钟同步

## 2. 网络与端口

| 服务 | 端口 | 对外 |
|------|------|------|
| gateway | 28100 | ✅ 唯一 HTTP 入口（经 Nginx/LB） |
| user-center | 28101 | ❌ 内网 |
| order | 28102 | ❌ 内网 |
| knowledge | 28104 | ❌ 内网 |
| ai | 28103 | ❌ 内网 |

Actuator `/actuator/prometheus` **仅管理网**，不经 Gateway 暴露。

## 3. 配置必查

- 全服务 `spring.redis.database` **一致**
- user-center：`captcha.enabled` 生产建议 true
- order：`moli.seckill.load-test-mode` **生产 false**
- knowledge：`kb.llm`、`kb.ingest.enabled`、MinIO
- gateway：CORS / HTTPS 在 Nginx/LB
- MyBatis：`log-impl: Slf4jImpl`（`deploy/*/application-pro.yml`）

## 4. 安全

- 改默认演示账号密码
- Swagger 生产限制暴露
- `/seckill/admin/init` 关闭 loadtest
- LLM Key 不在 Git

## 5. 数据

- 迁移脚本版本与 tag 一致（[[SQL迁移顺序]]）
- 发布前 DB 备份
- 计划 wiki Sync

## 6. 可观测性

| 项 | 检查 |
|----|------|
| 日志落盘 | 各服务 `logs/{service}.log` 正常滚动 |
| Alloy | 生产主机 tail 业务 log → Loki |
| Prometheus | 抓取内网 `/actuator/prometheus` |
| Grafana | 大盘 + Loki 数据源可用 |
| SkyWalking | Agent 可选；`SKYWALKING_ENABLED` 与 OAP 地址 |

详见 [[监控与日志]] · [[可观测性平台]]。

## 7. 签核

全部 P0 勾选后执行冒烟清单。

## 1. 日志落盘与 Loki

各服务 **dev / pro 统一** `logback-spring.xml` → 单文件 `{LOG_PATH}/{LOG_FILE}`。IDEA 工作目录须为仓库根（`$PROJECT_DIR$`），见 `docs/ops/idea-local-dev.md`。

| 服务 | 日志文件（dev） | Loki `service` 标签 |
|------|-----------------|---------------------|
| user-center | `moli-user-center/moli-user-center-server/logs/user-center-server.log` | `user-center-server` |
| gateway | `moli-gateway/logs/moli-gateway.log` | `moli-gateway` |
| order | `moli-order/moli-order-server/logs/order-server.log` | `order-server` |
| ai | `moli-ai/moli-ai-server/logs/ai-server.log` | `ai-server` |
| knowledge | `moli-knowledge/moli-knowledge-server/logs/knowledge-server.log` | `knowledge-server` |

**MyBatis SQL**：dev / pro 均 `log-impl: Slf4jImpl`（勿用 `StdOutImpl` / `NoLoggingImpl`）。SQL 以 DEBUG 写入上述文件，**Alloy tail → Loki**。改配置后须 Rebuild + 重启。

| 组件 | 作用 | 是否进 Loki |
|------|------|-------------|
| **Alloy** | tail `*.log` | ✅ |
| **SkyWalking Agent** | Trace / 拓扑 | ❌ |
| **IDEA 控制台** | stdout | ❌ |

发版后 15 分钟内各服务 **无 ERROR 持续刷屏**。

## 3. Grafana Explore 查日志

1. **Explore** → 数据源 **Loki**
2. **关掉 Live**；用 **Run query**
3. 时间范围：**Last 15 minutes** 或 **Last 1 hour**

示例 LogQL：

```logql
{service="user-center-server"} |= "覆盖值更新为"
{service="user-center-server"} | level="ERROR"
{service="user-center-server"} |= "Preparing"
```

查 SQL 时 **不要** 固定 `level=INFO`（SQL 为 DEBUG）。查不到时见 `deploy/observability/README.md`「Grafana 查不到日志」。

## 4. 健康探测

| 探测 | URL |
|------|-----|
| 网关 | `/OrderServer/seckill/ping` |
| 登录 | `POST /UserCenter/login` |
| 知识库 | `/KnowledgeServer/kb/index` |

五个 Java 服务暴露 `/actuator/health`、`/actuator/prometheus` — **不得经公网或 Gateway 暴露**。

见 [[测试文档索引]] 冒烟清单。

## 5. 知识库专项

- Sync 失败 → `kb_sync_log`、应用日志
- Lint CI → `python kb/tools/lint.py --strict`
- Web 页旧 → 是否 `sync-all`

## 6. 生产要点

1. 业务主机 **Alloy** tail `/opt/moli-project-distribute/moli-*/logs/*.log`
2. 监控机跑 Prometheus、Grafana、Loki、SkyWalking OAP/UI
3. `application-pro.yml`：`Slf4jImpl` + mapper 包 DEBUG（见各模块 `logback-spring.xml`）
4. SkyWalking 可选：`SKYWALKING_ENABLED=true`（`deploy/linux/moli-*.env.example`）

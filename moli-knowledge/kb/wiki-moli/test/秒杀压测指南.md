# 秒杀压测指南

> 秒杀架构 [[秒杀设计]]；loadtest 专用登录 [[茉莉-loadtest-账号]]；监控 [[茉莉-prometheus-大盘]]；环境 [[项目文档总览]]。

面向 **gateway → user-center / order 秒杀** 全链路压测的操作手册。压测前 checklist 与链路图见 [[秒杀全链路与压测要点汇总]]。

## 1. 架构

```
[秒杀压测指南 × N] → gateway:21000
            ├ /UserCenter/loadtest/login  → user-center（压测登录）
            └ /OrderServer/seckill/order  → order → Redis Lua
```

百万 QPS 需 **分布式 秒杀压测指南 + 多实例服务 + Redis Cluster**；单机 秒杀压测指南 通常 **5k~30k RPS**。

## 2. 环境准备

### 2.1 数据库

```powershell
cd D:\work\moli_project\moli-project-distribute
.\scripts\init-db.ps1
# 或执行 scripts/moli.sql + docs/sql/02_seckill_schema.sql
```

### 2.2 基础设施

| 组件 | 要求 |
|------|------|
| Nacos | 8848，namespace `dev` |
| Redis | **16379**，order loadtest 常用 **database 1** |
| MySQL | 库 `moli` |

Redis 未启动 → 登录/秒杀均失败，见 [[项目文档总览]]。

### 2.3 启动服务（loadtest profile）

```bash
# user-center
cd moli-user-center/moli-user-center-server
mvn spring-boot:run -Dspring-boot.run.profiles=loadtest

# gateway
cd moli-gateway
mvn spring-boot:run -Dspring-boot.run.profiles=loadtest

# order
cd moli-order/moli-order-server
mvn spring-boot:run -Dspring-boot.run.profiles=loadtest
```

### 2.4 初始化秒杀库存

```powershell
.\load-test\scripts\init-seckill-data.ps1 -Stock 1000000
```

## 3. 核心 API（经网关）

| 场景 | 方法 | 路径 |
|------|------|------|
| 压测登录 | POST | `/UserCenter/loadtest/login` |
| 秒杀下单 | POST | `/OrderServer/seckill/order` |
| 连通性 | GET | `/OrderServer/seckill/ping` |
| 指标 | GET | `/OrderServer/seckill/metrics` |

**勿用** `POST /UserCenter/login` 做 秒杀压测指南 压测（会查菜单/门户，慢）。见 [[茉莉-loadtest-账号]]。

登录体：`{"userName":"zhangsan","password":"123456"}`（演示密码见 `scripts/README.md`）

下单体：

```json
{ "activityId": 1, "userId": "u-12345", "requestId": "optional-key" }
```

响应：`200` 成功 / `409` 售罄 / `429` 重复

## 4. 推荐脚本阶梯

| 阶段 | 命令 | 说明 |
|------|------|------|
| 冒烟 | `.\load-test\scripts\run-smoke.ps1` | ~100 RPS 秒杀 |
| 登录冒烟 | `.\load-test\scripts\run-user-center-smoke.ps1` | 验证 loadtest 登录 |
| 混合 | `k6 run load-test/k6/mixed-login-seckill.js` | 登录+秒杀 |
| 本地 ramp | `.\load-test\scripts\run-user-center-ramp.ps1 -LoginPassword 123456` | 最高 ~300 RPS |
| 分布式 | `.\load-test\scripts\run-distributed-k6.ps1 -Workers 10 -TargetRps 100000` | 多 worker |

**注意**：旧版 login-ramp 目标 5000 RPS 单机易超时，`login ok` 低不等于密码错。

## 5. 压测前 checklist

-  三服务均为 **loadtest** profile
-  Redis 与 order 配置 **database 一致**
-  秒杀活动已 init，activityId=1 有库存
-  Gateway loadtest 路由含 Order/UserCenter（knowledge 可无）
-  可选：启动监控栈，见 [[茉莉-prometheus-大盘]]

## 6. 结果解读（简要）

- **409 比例高**：库存耗尽，正常
- **429 比例高**：重复 userId，检查脚本是否复用 id
- **502/504**：下游未注册或线程/连接池耗尽
- **login 失败**：Redis、密码、或 RPS 超单机能力

详细设计语义见 [[秒杀设计]]；Gateway 路由见 `moli-knowledge/kb/wiki/middleware/gateway-路由与过滤器.md`。

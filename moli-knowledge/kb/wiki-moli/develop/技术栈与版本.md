# 技术栈与版本

统一由 `moli-distribute-parent`（父 POM）做版本管理，各业务模块继承。

## 核心框架版本

| 组件 | 版本 |
|------|------|
| JDK | 1.8 |
| Spring Boot | 2.3.12.RELEASE |
| Spring Cloud | Hoxton.SR12 |
| Spring Cloud Alibaba | 2.2.7.RELEASE |
| Nacos | 2.0.3 |
| Sentinel | 1.8.1（**仅引依赖，未配置**） |

## 中间件 / 库版本

| 组件 | 版本 |
|------|------|
| MySQL | 8.0.3 |
| Redis | 5.0.13 |
| MyBatis-Plus | 3.4.2 |
| Druid | 1.1.14 |
| Shiro | 1.4.2 |
| shiro-redis | 3.1.0 |
| java-jwt | 3.8.2（依赖在，但鉴权实际用 Session 非 JWT，见 [[认证与会话机制]]） |
| Swagger (Springfox) | 2.9.2 |
| MinIO | 7.0.2 |
| EasyExcel | 2.2.10 |
| Hibernate Validator | 6.1.6.Final |
| Lombok | 1.18.6 |
| Fastjson | 1.2.46 |

## 能力 → 技术映射

| 能力 | 技术 |
|------|------|
| 服务发现/配置 | Nacos |
| 网关 | Spring Cloud Gateway |
| 负载均衡 | Ribbon（Hoxton 内置） |
| 熔断限流 | Sentinel（规划） |
| 服务调用 | 外部 HTTP + 服务间 Dubbo |
| 安全 | Shiro + Redis Session |
| 持久层 | MyBatis-Plus + Druid |
| 对象存储 | MinIO |
| 可观测（PoC 已落地） | **Prometheus + Grafana**（指标）· **Loki + Alloy**（日志）· **SkyWalking 9.7**（链路，可选 Agent） |

详见 [[可观测性平台]] · [[监控与日志]] · `docs/zh-CN/TECH_STACK.md`。

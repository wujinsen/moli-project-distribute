## 1. 背景与定位

本模块面向运维/技术人员，提供**基础设施资产台账**——记录云平台账号、服务器、中间件组件、项目部署信息及环境。

**不是**知识库运维，也不是业务运营；面向「机器和部署」层。前端在独立仓库 `meiling-ui`，后端在 `moli-user-center`。

---

## 2. 现状（已演进为可观测台账）

### 2.1 表结构（`scripts/moli.sql` + 增量迁移）

| 表 | 用途 |
|----|------|
| `operation_platform_info` | 云平台账号（密码 AES 加密） |
| `operation_server_info` | 服务器（含 `status`、`last_check_time`、**SSH 字段**） |
| `operation_component_deploy_info` | 组件部署（含健康字段 + 加密密码） |
| `operation_project_deploy_info` | 项目部署（含 `deploy_running`、`last_deploy_check_time`） |
| `operation_server_project` | 服务器↔项目 N:N |
| `operation_server_component` | 服务器↔组件 N:N |
| `operation_task` | 异步任务（部署启停 / 文件上传进度与日志） |

增量迁移：`docs/sql/17_operation_secret_view.sql`～`21_operation_ssh_deploy.sql`。

### 2.2 接口（`moli-user-center` · `/operation/*`）

四域 CRUD 均由 **Service 层**实现（加解密、探活 enrichment、端口矩阵、关联维护）：

| Controller | 前缀 | 扩展能力 |
|------------|------|----------|
| `OperationPlatformController` | `/operation/platform` | `GET/{id}/secret` |
| `OperationServerController` | `/operation/server` | `topology`、`check`、`GET/PUT links`、**`PUT/POST ssh`** |
| `OperationComponentController` | `/operation/component` | `check`、`secret` |
| `OperationProjectController` | `/operation/project` | 列表 VO 含 `portMatchStatus`、`deployRunning` |

跨域辅助：`OperationAuditController`（端口矩阵）、`OperationStatsController`（驾驶舱 KPI）、`OperationDeployController`（部署脚本 + **异步 task**）、`OperationHealthController`（批量探活）、**`OperationTaskController`**、**`OperationFileController`**（SFTP 上传）。

### 2.3 前端（meiling-ui）

| 菜单 | component | 页面 | 状态 |
|------|-----------|------|------|
| 项目管理 | `operation/project/index` | `ProjectManageView` | ✅ CRUD + 端口 badge + 进程状态列 |
| 服务器管理 | `operation/server/index` | `ServerManageView` | ✅ CRUD + 探活 + 拓扑 + 关联编辑 + **SSH 配置** |
| 平台管理 | `operation/platform/index` | `PlatformManageView` | ✅ CRUD + 密码管理 |
| 组件管理 | `operation/component/index` | `ComponentManageView` | ✅ CRUD + 探活 + 端口 badge + 密码 |
| **部署中心** | `operation/deploy/index` | `DeployCenterView` | ✅ 远程启停三件套 + 文件上传 + 任务日志 |

联调契约：`docs/api/operation-frontend.md`。

## 3. 路线图完成度

| 阶段 | 任务 | 状态 |
|------|------|------|
| P0 安全 | SVR-1/2/3 加密、审计、secret reveal | ✅ |
| P1 可观测 | SVR-4/5/6 探活、拓扑、前端状态灯 | ✅ |
| P2 联动 | SVR-7/8/9 端口矩阵、部署脚本、驾驶舱 stats | ✅ |
| 架构债 | SVR-10/11/12 ProjectService、links CRUD、定时探活 | ✅ |
| **P3 远程部署** | SVR-13~17 SSH、异步任务、远程启停、文件发布、部署中心 UI | ✅ |

腾讯云手工步骤可部分替代：[[腾讯云生产部署指南]] · 系统内 **部署中心**（内网 SSH 优先）。

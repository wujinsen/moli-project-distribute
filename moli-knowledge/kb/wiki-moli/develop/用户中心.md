# 用户中心（user-center-server）

茉莉微服务的**权限中枢**，也是整个系统的核心。提供用户/角色/菜单/部门/岗位/字典等能力，并作为 Dubbo Provider 向其它服务输出鉴权。

| 项 | 值 |
|----|----|
| 服务名 | `user-center-server` |
| HTTP 端口 | **8888**（旧文档写 1127，已过时） |
| Dubbo 端口 | 20881（version=1.0.0, group=moli） |
| 网关路由 | `/UserCenter/**` → StripPrefix=1 |

## 模块构成（4 个子模块）

| 子模块 | 职责 |
|--------|------|
| `moli-user-center-common` | RBAC 实体（SysUser/Role/Menu/Dept/Action…）、VO、`ShiroUtils`、`SHA256Util` |
| `moli-user-center-api` | Dubbo 契约 `UserCenterServer`（不在 common 里） |
| `moli-user-center-server` | 登录、Shiro 配置、CRUD、Dubbo Provider |
| `moli-user-center-shiro-starter` | 供 order/bi/knowledge 复用的会话校验 starter（旧名 `client`） |

## 职责

- 用户 / 角色 / 菜单 / 部门 / 岗位 / 字典 / 日志 的 CRUD 与授权管理（~70 个接口，清单见 `docs/api/user-center-api-map.md`）。
- 实现 [[rbac-权限模型]]（双轨：菜单 perms + 动作码 sys_action）。
- 登录认证与会话签发，详见 [[认证与会话机制]]。
- 作为 Dubbo Provider 输出 3 个接口给 [[订单服务]]、[[bi服务]]、[[知识库服务]]：
  - `getInfoByUserName(userName)`
  - `getUserById(userId)`
  - `getPermissionsByUserId(userId, userName)`

## 管理接口概览

| 模块 | 路径前缀 | 主要能力 |
|------|----------|----------|
| 用户 | `/user` | 用户 CRUD、角色分配、改密/重置、启停用 |
| 角色 | `/role` | 角色 CRUD、菜单+动作授权 |
| 菜单 | `/menu` | 菜单 CRUD、动态路由 `/menu/getRouters` |
| 部门 | `/dept` | 部门树 CRUD |
| 动作 | `/action` | 细粒度动作权限 CRUD |
| 多系统门户 | `/system` | 系统注册、进入、切换 |
| 认证 | `/login` `/logout` `/auth/capabilities` `/sso/validate` | 登录/登出/拉权限/SSO |

操作指引见 [[权限管理操作指南]]。

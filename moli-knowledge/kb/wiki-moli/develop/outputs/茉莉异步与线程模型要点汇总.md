# 茉莉异步与线程模型要点汇总

> **Query crystallize**：Spring MVC 栈下异步、线程、缓存注解与可观测性如何落地。

## 1. 线程模型总览

| 线程来源 | 用途 | 页 |
|----------|------|-----|
| Tomcat HTTP | 同步 API | `moli-knowledge/kb/wiki/java/tomcat与-servlet容器.md` |
| Dubbo/Feign | RPC 客户端/服务端 | `moli-knowledge/kb/wiki/middleware/dubbo-调用原理与分层.md` |
| 自定义线程池 | @Async、CF、批处理 | `moli-knowledge/kb/wiki/spring/spring-async与线程池.md` `moli-knowledge/kb/wiki/spring/spring-async与线程池.md` |
| 虚拟线程（可选） | 高并发阻塞 IO | [[茉莉-演进-虚拟线程]] |

**原则**：IO 密集任务**不要**占 Tomcat 线程；**独立命名池** + 拒绝策略 + 监控。

## 2. 异步选型

```
非关键、同进程、可丢 ──▶ @Async（小池）
跨服务、需重试     ──▶ MQ `moli-knowledge/kb/wiki/middleware/rocketmq-架构与实战.md`
并行查多源         ──▶ CompletableFuture + 专用池
全链路非阻塞       ──▶ WebFlux（新服务才考虑）[[webflux-响应式入门]]
秒杀核心下单       ──▶ 同步 Redis Lua + 异步落库 [[秒杀设计]]
```

## 3. 上下文与日志

- Shiro `Subject`、MDC `traceId` 依赖 ThreadLocal `moli-knowledge/kb/wiki/security/threadlocal-与上下文传递.md`
- 线程池 / @Async 必须 **TTL 或 MDC 拷贝** `moli-knowledge/kb/wiki/java/transmittable-thread-local跨线程.md` `moli-knowledge/kb/wiki/java/mdc-日志链路上下文.md`
- 生产链路优先 **SkyWalking** [[茉莉可观测性与运维体系汇总]]

## 4. 缓存注解栈

| 层级 | 技术 | 场景 |
|------|------|------|
| L1 | Caffeine | 活动页、字典 `moli-knowledge/kb/wiki/cache/caffeine-本地缓存实践.md` |
| L2 | Redis + `@Cacheable` | 用户、权限 `moli-knowledge/kb/wiki/spring/spring-cache-注解缓存.md` |
| 一致性 | Cache-Aside + evict | `moli-knowledge/kb/wiki/cache/缓存双写与一致性策略.md` |

## 5. 上线 checklist

-  禁用 `SimpleAsyncTaskExecutor` 于生产
-  线程池队列有界，拒绝策略明确
-  异步异常有 `AsyncUncaughtExceptionHandler`
-  Gateway 透传 traceId
-  压测验证线程池队列与 Tomcat 不互相拖死 [[压测报告解读指南]]

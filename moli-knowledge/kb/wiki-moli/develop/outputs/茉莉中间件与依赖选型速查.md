# 茉莉中间件与依赖选型速查

> **Query crystallize**：综合 [[技术栈与版本]]、[[茉莉微服务全链路一张图]] 等。版本以代码为准。

## 1. 总览表

| 中间件 | 版本建议 | 职责 | 未启动典型症状 |
|--------|----------|------|----------------|
| **Nacos** | 2.0.3 | 注册 + 配置 | Dubbo No provider [[项目文档总览]] |
| **MySQL** | 8.0 | 业务库 | 连接失败、500 |
| **Redis** | 5.x | Shiro Session、秒杀 | 登录 500/401 [[茉莉登录与鉴权故障根因汇总]] |
| **Dubbo** | 2.7.x | 内部 RPC | 跨服务调用户失败 |
| **Gateway** | SCG | 统一 HTTP 入口 | 外网无法访问 |
| **MinIO** | — | 知识库附件 | 上传失败 [[项目文档总览]] |
| **ES** | 7.x | 检索（规划） | 搜索降级 [[知识库-meilisearch接入规划]] |
| **MQ** | RocketMQ/Kafka | 异步（演进） | 当前 Redis 队列 [[秒杀设计]] |

## 2. 注册 vs 配置

- **Nacos Discovery**：服务实例列表 → Dubbo/Gateway [[茉莉-nacos-dev命名空间]]
- **Nacos Config**：`application-*.yml` 动态刷新 `moli-knowledge/kb/wiki/middleware/nacos-config动态配置实践.md`

## 3. 缓存 vs 消息

| | Redis | RocketMQ/Kafka |
|---|-------|----------------|
| 茉莉现状 | Session+秒杀+锁 | 未默认部署 |
| 选型 | 必装 | 量大后削峰 [[茉莉-mq-选型]] |

## 4. 协调 / 锁

- **ZK**：不装（Nacos 替代）`moli-knowledge/kb/wiki/middleware/zookeeper-与协调服务.md`
- **分布式锁**：Redis Lua / Redisson `moli-knowledge/kb/wiki/cache/redis分布式锁实现.md`

## 5. 本地最小集

[[茉莉新人上手checklist]]：Nacos + MySQL + Redis → user-center → gateway。

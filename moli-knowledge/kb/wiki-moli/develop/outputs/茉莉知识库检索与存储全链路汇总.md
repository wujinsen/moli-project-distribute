# 茉莉知识库检索与存储全链路汇总

> **Query crystallize**：wiki 编译、DB 同步、ES 索引与 Ask 检索一条线。

## 1. 存储与职责

| 层 | 介质 | 职责 |
|----|------|------|
| 源 | `raw/` | 只读投喂 [[增量ingest与raw投喂指南]] |
| 知识 | `wiki/*.md` | Agent 维护、互链 [[知识库三操作]] |
| 结构化 | MySQL `kb_*` | 门户 CRUD、权限 [[项目文档总览]] |
| 检索 | ES（规划） | BM25/混合 [[知识库-meilisearch接入规划]] |
| 附件 | MinIO | 二进制 [[项目文档总览]] |

## 2. 同步路径

```
Ingest 批次 → wiki 页 + log.md + edges.jsonl
            → sync_to_db.py → MySQL
            → (规划) indexer → ES [[kb-wiki到es同步流水线]]
```

中文分词 `moli-knowledge/kb/wiki/search/elasticsearch-ik分词与分析器.md`；CDC 可选 `moli-knowledge/kb/wiki/database/mysql-binlog与canal同步.md`。

## 3. 查询路径

| 模式 | 路径 |
|------|------|
| Agent Query | index.md → ≤15 页 [[项目文档总览]] |
| 用户 Ask | API 检索 + LLM（混合检索规划） |
| Crystallize | 综合页 `outputs/` |

## 4. 服务边界

[[项目文档总览]] 经 Gateway `/KnowledgeServer/**`；鉴权同 [[项目文档总览]]。

## 5. checklist

-  ingest 后 dry-run + sync DB
-  index.md 批次索引更新
-  ES mapping 与 wiki slug 一致
-  附件 URL 不进 ES 正文

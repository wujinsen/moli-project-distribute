# 可观测性平台

> 工程契约：`docs/design/observability-platform-plan.md` · 日常 Runbook：[[监控与日志]]

## 1. 定位

茉莉 v1 后增量交付 **本地 / 预发 PoC 可观测栈**，覆盖三类信号：

| 信号 | 组件 | 说明 |
|------|------|------|
| **指标** | Prometheus + Grafana | 抓取 `/actuator/prometheus` |
| **日志** | Loki + Grafana Alloy | tail 各服务 `logs/{service}.log` |
| **链路** | Apache SkyWalking 9.7 | Java Agent → OAP；**不**推送日志到 Loki |

部署拓扑：`docs/diagrams/png/moli-observability-platform.png`（源：`docs/diagrams/moli-observability-platform.drawio`）

## 2. 本地启动

```powershell
docker compose -f deploy/observability/docker-compose.observability.yml up -d
```

| 组件 | 端口 |
|------|------|
| Grafana | **28300** |
| Loki | **28110** |
| Alloy UI | **28111** |
| Prometheus | **29090** |
| SkyWalking UI | **28120** |
| SkyWalking OAP gRPC | **28121** |

Java 服务 IDEA 启动可挂 SkyWalking Agent（`.run/* (dev).run.xml` 已配置 VM options）。

## 3. 日志链路（关键）

```
logback FILE → *.log on disk → Alloy tail → Loki → Grafana Explore
```

- **统一 logback**：dev 控制台 + 文件；pro 仅文件
- **MyBatis `Slf4jImpl`**：SQL 以 DEBUG 进 log 文件（dev / pro 一致）
- **IDEA 控制台 ≠ Loki**：旧版 `StdOutImpl` 只写 stdout，不会被 Alloy 采集

## 4. 与业务端口对照

业务服务端口见 [[本地启动指南]]（28100 网关、28101 user-center…）。可观测组件端口见 `docs/ops/local-dev-ports.md`。

## 5. 生产演进

PoC Compose 适用于开发/预发验证。生产建议：

- 业务机：Alloy + 可选 SkyWalking Agent
- 监控机：Prometheus、Grafana、Loki、SkyWalking OAP/UI（内网）
- Actuator / metrics **管理网访问**，不经 Gateway 暴露

详见 `docs/design/observability-platform-plan.md` §生产与高可用。

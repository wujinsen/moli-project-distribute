# 知识库使用指南

> 服务实体 [[知识库服务]]；登录 [[登录与鉴权指南]]；完整 API 见项目 `docs/KNOWLEDGE_API.md`。

面向「浏览 wiki、问答、管理文档」的操作说明（经网关）。

## 1. 访问地址

| 方式 | Base URL |
|------|----------|
| **经网关（推荐）** | `http://127.0.0.1:21000/KnowledgeServer` |
| 直连 | `http://127.0.0.1:8090` |

前置：Nacos + MySQL + Redis + [[用户中心]] + [[网关]] + knowledge-server 已启动；执行 `docs/sql/03_knowledge_schema.sql`。

## 2. 鉴权

除白名单外，请求头：

```
Authorization: login_token_xxxxxxxx
```

token 来自 `POST /UserCenter/login`（见 [[登录与鉴权指南]]）。

## 3. 常用接口（服务内路径）

| 场景 | 方法 | 路径 |
|------|------|------|
| 目录 meta | GET | `/kb/index?spaceId=`（分组计数，轻量首屏） |
| 分组条目 | GET | `/kb/index/items?spaceId=&type=&pageNum=&pageSize=` |
| 目录搜索 | GET | `/kb/index/search?spaceId=&q=` |
| slug 定位 | GET | `/kb/index/locate?spaceId=&slug=` |
| 单页 Markdown | GET | `/kb/page?slug=develop/用户中心` |
| 智能问答 | POST | `/kb/ask` |
| 关系图谱 | GET | `/kb/graph?mode=&maxNodes=&minDeg=`（大库度数裁剪 + meta） |
| 图谱邻域子图 | GET | `/kb/graph/ego?docId=&depth=` |
| 体检 | GET | `/kb/lint` |
| 文档搜索 | GET | `/kb/document/search?source=kb` |
| Wiki 编辑（写正文） | PUT | `/kb/wiki-moli/page` → 再 Wiki 同步 |
| ~~保存文档~~ | ~~POST~~ | ~~`/kb/document`~~ **已停用**（2026-06-24） |

经网关示例：

```bash
curl "http://127.0.0.1:21000/KnowledgeServer/kb/page?slug=guides/本地启动指南" \
  -H "Authorization: login_token_xxx"
```

## 4. 问答 `/kb/ask`

```json
POST /kb/ask
{ "question": "Spring 事务什么时候失效？", "spaceId": null, "topK": 8 }
```

多空间（须对每个 space 有读权限）：

```json
POST /kb/ask
{
  "question": "对比企业规范与日本语考试要点",
  "spaceIds": [900000000000000001, 900000000000000002],
  "topK": 8
}
```

| 字段 | 说明 |
|------|------|
| `question` | 必填 |
| `spaceId` | 单空间；省略=全部可读空间 |
| `spaceIds` | 多空间数组；非空时优先于 `spaceId` |
| `topK` | 候选页数，默认 8 |

响应 `mode`：`generative`（配了 LLM）或 `retrieval`（仅检索）；`citations[]` 含 slug，与 wiki `[[slug]]` 对应。

**扩展能力（默认关，不影响本接口）**：

| 能力 | 路径 | 说明 |
|------|------|------|
| Agentic 问答 | `POST /kb/ask/agentic` | 多跳 + 自检（AI-7） |
| 主题调研 | `POST /kb/research` | 多节报告 + 可选 Ingest 回写（AI-10） |

详见 [[AI能力操作指南]] · [[DeepResearch调研指南]]。

## 5. 空间与权限

- 默认演示空间 `spaceId=900000000000000001`（`enterprise-kb`，公开）
- 茉莉系统手册 `spaceId=900000000000000003`（`moli-ops-manual`），种子见 `docs/sql/07_kb_space_ops_manual.sql`
- **visibility**：公开 / 内部 / 私有；**成员角色** viewer / editor / admin
- 省略 `spaceId` / `spaceIds` 时后端只返回当前用户**可读**空间内的内容
- 平台超管（`superadmin`/`admin`）可管理所有空间；普通用户仅能通过 `kb_space_member` 访问被分配的空间

## 6. markdown 与 wiki 同步

权威内容在 `moli-knowledge/kb/wiki-moli/`（茉莉手册）与 `kb/wiki/`（enterprise-kb 占位）。设计哲学见 [[知识库设计哲学-docs-as-code]]；契约见 [[知识库三操作]]；逐步操作见 [[wiki同步指南]]；**增量投喂**见 [[增量ingest与raw投喂指南]]；DB 前置见 [[数据库初始化指南]]。

**删除文档**：Web 暂无删除按钮；删 wiki 源文件后执行 Sync（DB 软删）。步骤见 [[知识库设计哲学-docs-as-code]] §5.1。

```bash
bash moli-knowledge/kb/tools/ci/run_sync.sh dry-run-all
bash moli-knowledge/kb/tools/ci/run_sync.sh sync-all
```

同步后 `/kb/page` 的 `outLinks/backLinks` 才有 `kb_relation` 数据。

**Query / Lint**：详见 [[查询与体检指南]]。要点——**`lint.py` 扫 wiki 文件**（Sync 前）；**Web「健康体检」扫 MySQL**（Sync 后 + 工单 `kb_lint_issue`），二者不能互相替代。

## 7. 附件（MinIO）

上传/下载/删除见 [[minio-附件存储指南]]。需本地 MinIO（9000）与 `minio.bucket=moli-knowledge`。

## 8. SSO 门户入口

用户在 `sys_user_system` 绑定 `moli-knowledge`（id=39）后，登录可见门户卡片，见 [[认证与会话机制]]。

## 9. 返回体

统一 `MoliResult`：`code=200` 成功；`401/403` 鉴权失败。

详细字段与 CRUD 见 `docs/KNOWLEDGE_API.md`。

# 日本語試験知识库说明

本目录为 **私有空间** `jp-fe-ap-exam`，与企业 wiki（`enterprise-kb`）同库不同 `space_id`。

## raw 投喂位置

FE/AP/Certify 语料目录见 `wiki-jp-exam/index.md` 表格：

- **`kb/raw/school/fe/`** — 基本情報
- **`kb/raw/school/ap/`** — 応用情報
- **`kb/raw/school/certify/`** — Certify サーティファイ（→ **`wiki-jp-exam/certify/`**，入口 [[Certifyサーティファイ]]；中文题干维护见该页 §中文题干维护）

**本说明页不使用目录级 `sources` 占位**（如 `raw/school/fe/` 整目录），避免 Ingest 误报「簇已引用」。各 wiki 文章在 frontmatter 写 **精确文件**：

```yaml
sources:
  - raw/school/fe/fe_kamoku_b_set_sample_qs.md
```

## Ingest 与 Sync

1. Agent 或 Web Ingest 工作台读 `raw/school/fe/*.md` → 写/补 **`wiki-jp-exam/**`**
2. `python kb/tools/lint.py --strict`
3. `bash kb/tools/ci/run_sync.sh sync-all`（含 `jp-fe-ap-exam`）

映射表见茉莉手册 `wiki-moli/ops/wiki同步指南.md` §1。

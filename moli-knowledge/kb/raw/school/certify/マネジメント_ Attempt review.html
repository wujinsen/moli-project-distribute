Question text


プロジェクトの進捗管理に用いられるチャートであり，全作業を幾つかの項目に分け，各項目の作業期間について，予定と実績をそれぞれ帯（横棒）で表して対比させたものはどれか。

Select one:

Feedback


PDPC : (Process Decision Program Chart)は，事態が発生した時点から，状況の推移，判断，打つべき対策などを順番に連結して，事態の終息までの計画を図解で表現する。
ガントチャート : 予定と実績をそれぞれ帯（横棒）で表して対比させたもの
トレンドチャート:プロジェクトにおいて，費用と工程の消化度を表す折れ線グラフを，予算と実紹について対比させて描くことにより，プロジェクトの進捗を把握する。
レーダーチャート: 図の中心を原点として複数の項目の軸を放射状に描き，それぞれの軸上に各項目の値をプロットし，隣り合う項目間を線で連結した多角形を描くことにより，複数の項目間のバランスや全体的な傾向を表現する。
The correct answer is: ガントチャート

Question text


開発するシステムが保持している外部入力，外部出力，外部照会，内部論理ファイル，外部インタフェースファイルの個数と開発の難易度や，システムとしての複雑さの補正係数を用いて，システムの開発規模を見積もる方法はどれか。

Select one:

Feedback


COCOMO(COnstructive COst MOdel)
　開発形態に応じた組織モード，半組込みモード，組込みモードがあり，システムの規模から算出したエ数をシステムの難易度や開発要員の能力による係数で調整して開発工数を箕出する。
標準タスク法
  システム開発の全工程を作業単位に分解し，あらかじめ設定してある標準的な工数を各作業単位に割り当て，各作業単位に割り当てたエ数を合計することにより，全工程の開発工数を算出する。
プログラムステップ法
  プログラムのステップ数を総計することによって，システムの開発工数を算出する。
The correct answer is: ファンクションポイント法

Question 6

Correct
Mark 1.00 out of 1.00
Flag question

Question text


あるプロジェクトにおいて，次の条件で，作業の進捗の遅れは何日か。
〔条件〕
(1) 本来， 120項目の作業を24日間で完了する予定であった。
(2) 全ての作業は，作業堡が等しいものとする。
(3) 現在， 15日間が終わった時点で，完了した作業は60項目である。
(4) 作業の進捗の遅れは，現在完了した作業項目が本来終わっていなければならない日数との差とする。

Select one:

Feedback


想定された1日当たりの作業量は？
　120(項目)/24(日)=5(項目/日)

現在完了した作業項目が本来終わっていなければならない日数は？
　60(項目)/5(項目/日)=12(日)

作業の遅れ
　15-12=3(日)
The correct answer is: 3

Question text


A 店では，次に示す方式によって顧客サービスシステムで使用するデータベースのバックアップをとっている。木曜日の業務中にデータベースを格納しているハードディスク装醤が障害を起こしたため，新しいハードディスク装置を用意して，水曜日の業務終了後の状態にデータベースを復旧することになった。
データベースの復旧に必要となるバックアップ用のテープはどれか。
ここで， A店は年中無休で業務を行っており，業務時間は毎日10時～22時である。

〔方式〕
(1) 日曜日の業務終了後に，フルバックアップ（データベースの全データのバックアップ）を行う。
(2) 月曜日～土曜日の業務終了後に，増分バックアップ（前回の“フルバックアップ又は増分バックアップ’'以降に更新されたデータだけのバックアップ）を行う。
(3) 毎日のバックアップのデータは1本のテープに格納される。また， 1本のテープには， 1日分のバックアップのデータだけを格納する。

Select one:

Feedback


障害発生　：　木曜日
データ　 ：　水曜日の業務終了後

月～土は前回以降に更新されたデータだけバックアップ（業務終了後～翌日の業務終了後　1日分）
日曜日　：　フルバックアップ
月曜日　：　増分バックアップ
火曜日　：　増分バックアップ
水曜日　：　増分バックアップ
⇒ここで障害発生
木曜日　：　増分バックアップ
金曜日　：　増分バックアップ
土曜日　：　増分バックアップ
The correct answer is: ‘‘日曜日，月曜日，火曜日，水曜日’'のテープだけ

Question text


データベースを利用した顧客サービスシステムにおいて， 1年前と比較して応答時間が大幅に長くなるという問題が発生した。この問題を解決する有効な方法になり得るものはどれか。ここで，データベースは，データの新規登録，削除，更新が頻繁に行われている。

Select one:

Feedback


プログラムを再インストール：　データベース本体の問題であるため，プログラムの再インストールは有効な方法になり得ない。
データベースの再編：　データベースの再編成によって，記箆域の断片化が解消されるため，有効な方法になり得る。
バックアップ回数を増やす：　データベース本体の問題であるため，データベースのバックアップ間隔の変更は有効な方法になり得ない。
DBMSを再インストール：　データベース本体の問題であるため， DBMSの再インストールは有効な方法になり得ない。
The correct answer is: データベースの再編成を実施する。

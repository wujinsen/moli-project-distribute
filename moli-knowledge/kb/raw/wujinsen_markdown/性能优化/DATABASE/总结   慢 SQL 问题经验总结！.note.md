# 4、误操作、程序 bug时怎么办，解决⽅案

提出这个问题显然主要是针对刚开始⼯作的年轻同⾏们 …实际上误操作和程序 bug 导致数据误 删或者混乱的问题并⾮少⻅，但是刚⼊⾏的开发⼯作者会⽐较紧张。⼀个成熟的企业往往会有完 善的数据管理规范和较丰富的数据恢复⽅案（初创公司除外），会进⾏数据备份和数据容灾。 当你发现误操作或程序 bug 导致线上数据被误删或误改动时，⼀定不能慌乱，应及时与 DBA 联 系，第⼀时间进⾏数据恢复（严重时直接停⽌服务），尽可能减少影响和损失。对于重要数据 （如资⾦）的操作，在开发时⼀定要反复进⾏测试，确保没有问题后再上线。

# 解决提示：centos No module named yum 的问题

centos 在执⾏yum的时候报错： [root@localhost ~]# yum There was a problem importing one of the Python modules required to run yum. The error leading to this problem was: No module named yum Please install a package which provides this module, or verify that the module is installed correctly. It's possible that the above module doesn't match the current version of Python, which is: 2.7.8 (default, Nov 24 2015, 15:31:38) [GCC 4.4.7 20120313 (Red Hat 4.4.7-16)] If you cannot solve this problem yourself, please go to the yum faq at: http://yum.baseurl.org/wiki/Faq

⼤多数是python升级导致的。 查看python版本： [root@localhost ~]# ls /usr/bin/|grep python abrt-action-analyze-python python python2 python2.6.6 python-config

修改python解释器地址： vim /usr/bin/yum 修改第⼀⾏#!/usr/bin/python改为#!/usr/bin/python2.6.6 如果还是报错，需要检查⼀下python2.6.6的python是不是可以正常使⽤的。

在python交互终端上输⼊如下命令： >>> import yum Traceback (most recent call last): File "<stdin>", line 1, in <module> ImportError: No module named yum

查看是否有yum模块： ls /usr/lib/python2.6/site-packages/yum 看这个⽬录下⾯是否有东⻄，没有东⻄说明下⾯确定什 么都没有了。 如果这个⽬录存在在检查⼀下，python2.6.6是否可以正常import其他模块。

例如：import os 如果不能正常import 说明/usr/lib64/python2.6这个⽬录已经损坏或者不能使⽤了。 如果没了只能从其他服务器上拷⻉⼀个过来，这样就可以了。

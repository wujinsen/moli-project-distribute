clas ExB extends ExA { public static void test(){ System.out.println("⼦类 -静态⽅法"); } static { System.out.println("⼦类 -静态代码块"); }

总结：

- 1、它⾸先去看⽗类⾥⾯有没有静态代码块，如果有，它先去执⾏⽗类⾥⾯静态代码块


⾥⾯的内容，当⽗类的静态代码块⾥⾯的内容执⾏完毕之后， 接着去执⾏⼦类(⾃⼰这个 类)⾥⾯的静态代码块，

- 2、当⼦类的静态代码块执⾏完毕之后，它接着⼜去看⽗类有没有⾮静态代码块，如果

启动docker:

systemctl start docker

获取镜像: docker pul ubuntu

启动新容器: docker run -it ubuntu /bit/bash

查看所有容器: docker ps -a 启动已停⽌的容器: docker start container_id

# 后台运⾏

在⼤部分的场景下，我们希望 docker 的服务是在后台运⾏的，我们可以过 -d 指定容器的运⾏模式。

$ docker run -itd --name ubuntu-test ubuntu /bin/bash

docker run -d -p 81 80 nginx

docker run -p 80:80 -v /data:/data -d nginx:latest 前⼀个是容器端⼝⽬录，后⼀个是主机端⼝⽬录

Bl om Filter是⼀种空间效率很⾼的随机数据结构，它利⽤位数组很简洁地表⽰⼀个集合，并能判断⼀ 个元素是否属于这个集合。Bl om Filter的这种⾼效是有⼀定代价的：在判断⼀个元素是否属于某个集 合时，有可能会把不属于这个集合的元素误认为属于这个集合（false positive）。因此，Bl om Filter 不适合那些“零错误”的应⽤场合。⽽在能容忍低错误率的应⽤场合下，Bl om Filter通过极少的错误换 取了存储空间的极⼤节省。

集合表示和元素查询

下⾯我们具体来看Bl om Filter是如何⽤位数组表⽰集合的。初始状态时，Bl om Filter是⼀个包含m位 的位数组，每⼀位都置为0。

为了表达S={x1, x2,…,xn}这样⼀个n个元素的集合，Bl om Filter使⽤k个相互独⽴的哈希函数（Hash Function），它们分别将集合中的每个元素映射到{1,…,m}的范围中。对任意⼀个元素x，第i个哈希函 数映射的位置hi(x)就会被置为1（1≤i≤k）。注意，如果⼀个位置多次被置为1，那么只有第⼀次会起 作⽤，后⾯⼏次将没有任何效果。在下图中，k=3，且有两个哈希函数选中同⼀个位置（从左边数第五 位）。

## 总结

在计算机科学中，我们常常会碰到时间换空间或者空间换时间的情况，即为了达到某⼀个⽅⾯的最优 ⽽牺牲另⼀个⽅⾯。Bl om Filter在时间空间这两个因素之外又引⼊了另⼀个因素：错误率。在使⽤ Bl om Filter判断⼀个元素是否属于某个集合时，会有⼀定的错误率。也就是说，有可能把不属于这个

集合的元素误认为属于这个集合（False Positive），但不会把属于这个集合的元素误认为不属于这个 集合（False Negative）。在增加了错误率这个因素之后，Bl om Filter通过允许少量的错误来节省⼤ 量的存储空间。

⾃从Burton Bl om在70年代提出Bl om Filter之后，Bl om Filter就被⼴泛⽤于拼写检查和数据库系统 中。近⼀⼆⼗年，伴随着⽹络的普及和发展，Bl om Filter在⽹络领域获得了新⽣，各种Bl om Filter变 种和新的应⽤不断出现。可以预见，随着⽹络应⽤的不断深⼊，新的变种和应⽤将会继续出现，Bl om Filter必将获得更⼤的发展。

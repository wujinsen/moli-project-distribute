# 第一章、推荐简介

![image 9](<58同城推荐系统设计与实现-沈剑_images/imageFile9.png>)

推荐简介

- • 用户在在某个场景下对某个商品或信息产生了某种行为，系统会对另 一些商品或信息进行推荐
- • 要素：


- （1）用户 - user
- （2）场景 - scene
- （3）商品或信息 - item
- （4）行为 - action
- （5）系统 - recommendation-system
- （6）推荐结果集合 - recommendation-result / item-set

# 什么是OLAP编辑

联机分析处理 (OLAP) 的概念最早是由关系数据库之⽗E.F.Cod于193年提出的，他同时提出了关于 OLAP的12条准则。OLAP的提出引起了很⼤的反响，OLAP作为⼀类产品同联机事务处理(OLTP) 明显 区分开来。 下表列出了OLTP与OLAP之间的⽐较。 OLAP是使分析⼈员、管理⼈员或执⾏⼈员能够从多⻆度对信息进⾏快速、⼀致、交互地存取,从⽽获得 对数据的更深⼊了解的⼀类软件技术。OLAP的⽬标是满⾜决策⽀持或者满⾜在多维环境下特定的查询 和报表需求,它的技术核⼼是"维"这个概念。 “维”是⼈们观察客观世界的⻆度,是⼀种⾼层次的类型划分。“维”⼀般包含着层次关系,这种层次关系有 时会相当复杂。通过把⼀个实体的多项重要的属性定义为多个维(dimension)，使⽤户能对不同维上的 数据进⾏⽐较。因此OLAP也可以说是多维数据分析⼯具的集合。 OLAP的基本多维分析操作有钻取（rol up和dril down）、切⽚（slice）和切块（dice）、以及旋转 （pivot）、dril acros、dril through等。 ·钻取是改变维的层次，变换分析的粒度。它包括向上钻取（rol up）和向下钻取（dril down）。rol up是在某⼀维上将低层次的细节数据概括到⾼层次的汇总数据，或者减少维数；⽽dril down则相反， 它从汇总数据深⼊到细节数据进⾏观察或增加新维。 ·切⽚和切块是在⼀部分维上选定值后，关⼼度量数据在剩余维上的分布。如果剩余的维只有两个，则 是切⽚；如果有三个，则是切块。 ·旋转是变换维的⽅向，即在表格中重新安排维的放置（例如⾏列互换）。 OLAP有多种实现⽅法，根据存储数据的⽅式不同可以分为ROLAP、MOLAP、HOLAP。 ROLAP表示基于关系数据库的OLAP实现（Relational OLAP）。以关系数据库为核⼼,以关系型结构进 ⾏多维数据的表示和存储。ROLAP将多维数据库的多维结构划分为两类表:⼀类是事实表,⽤来存储数据 和维关键字;另⼀类是维表,即对每个维⾄少使⽤⼀个表来存放维的层次、成员类别等维的描述信息。维 表和事实表通过主关键字和外关键字联系在⼀起,形成了"星型模式"。对于层次复杂的维,为避免冗余数 据占⽤过⼤的存储空间,可以使⽤多个表来描述,这种星型模式的扩展称为"雪花模式"。 MOLAP表示基于多维数据组织的OLAP实现（Multidimensional OLAP）。以多维数据组织⽅式为核⼼, 也就是说,MOLAP使⽤多维数组存储数据。多维数据在存储中将形成"⽴⽅块（Cube）"的结构,在 MOLAP中对"⽴⽅块"的"旋转"、"切块"、"切⽚"是产⽣多维数据报表的主要技术。 HOLAP表示基于混合数据组织的OLAP实现（Hybrid OLAP）。如低层是关系型的，⾼层是多维矩阵型 的。这种⽅式具有更好的灵活性。 还有其他的⼀些实现OLAP的⽅法，如提供⼀个专⽤的SQL Server，对某些存储模式（如星型、雪⽚ 型）提供对SQL查询的特殊⽀持。

OLAP⼯具是针对特定问题的联机数据访问与分析。它通过多维的⽅式对数据进⾏分析、查询和报表。 维是⼈们观察数据的特定⻆度。例如，⼀个企业在考虑产品的销售情况时，通常从时间、地区和产品 的不同⻆度来深⼊观察产品的销售情况。这⾥的时间、地区和产品就是维。⽽这些维的不同组合和所 考察的度量指标构成的多维数组则是OLAP分析的基础，可形式化表示为（维1，维2， …，维n，度量 指标），如（地区、时间、产品、销售额）。多维分析是指对以多维形式组织起来的数据采取切⽚ （Slice）、切块（Dice）、钻取（Dril-down和Rol-up）、旋转（Pivot）等各种分析动作，以求剖析 数据，使⽤户能从多个⻆度、多侧⾯地观察数据库中的数据，从⽽深⼊理解包含在数据中的信息。 根据综合性数据的组织⽅式的不同，常⻅的OLAP主要有基于多维数据库的MOLAP及基于关系数据库 的ROLAP两种。MOLAP是以多维的⽅式组织和存储数据，ROLAP则利⽤现有的关系数据库技术来模拟 多维数据。在数据仓库应⽤中，OLAP应⽤⼀般是数据仓库应⽤的前端⼯具，同时OLAP⼯具还可以同 数据挖掘⼯具、统计分析⼯具配合使⽤，增强决策分析功能。

# K-Means算法应⽤

看到这⾥，你会说，K-Means算法看来很简单，⽽且好像就是在玩坐标点，没什么真实⽤处。⽽且， 这个算法缺陷很多，还不如⼈⼯呢。是的，前⾯的例⼦只是玩⼆维坐标点，的确没什么意思。但是你 想⼀下下⾯的⼏个问题：

- 1）如果不是⼆维的，是多维的，如5维的，那么，就只能⽤计算机来计算了。
- 2）⼆维坐标点的X，Y 坐标，其实是⼀种向量，是⼀种数学抽象。现实世界中很多属性是可以抽象成 向量的，⽐如，我们的年龄，我们的喜好，我们的商品，等等，能抽象成向量的⽬的就是可以让计算 机知道某两个属性间的距离。如：我们认为，18岁的⼈离24岁的⼈的距离要⽐离12岁的距离要近，鞋 ⼦这个商品离⾐服这个商品的距离要⽐电脑要近，等等。 只要能把现实世界的物体的属性抽象成向量，就可以⽤K-Means算法来归类了。 在《 》 这篇⽂章中举了⼀个很不错的应⽤例⼦，作者⽤亚洲15⽀⾜球队的205 年到1010年的战绩做了⼀个向量表，然后⽤K-Means把球队归类，得出了下⾯的结果，呵呵。

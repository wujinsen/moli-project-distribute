以管理员身份运⾏命令提示符：依次点击“开始”—“所有程序”—“附件”，找到“命令提示符”，右键单 击，然后选择以“管理员身份运⾏”。

在命令提示符中输⼊命令： netsh wlan show drivers ，在输出的内容中找到“⽀持的承载⽹络”，看看 后⾯写的是“是”还是“否”。如果是“否”，就说明你的⽆线⽹卡不⽀持AP模式，接下去的步骤不⽤做， 电脑不⽀持该功能。。。

在命令提示符中输⼊命令：netsh wlan set hostednetwork mode=alowsid=senfeng key=senfengbailing9（密码⻓度最少8位，否则⽆效）。命令会提示承载⽹络已经启动之类，⽆视即 可。

依次点击“控制⾯板”—“⽹络和Internet”—"查看⽹络状态和任务”—“更改适配器设置”，你会发现多了⼀ 个Microsoft Virtual wlan Miniport Adapter，这个就是我们刚才步骤3命令虚拟出来的⽆线⽹络适配 器。

在命令提示符中输⼊命令：netsh wlan start hostednetwork 。打开虚拟的⽆线路由器。

打开“⽹络共享中⼼”可以看到你现在连接了两个⽹络，⼀个是你的有线⽹络，另外⼀个就是虚拟⽹络 （笔记本⼀般显示的是“⽆线⽹络2”）。

在“更改适配器设置”⾥⾯，右击“本地连接”（也就是你连⼊⽹络的有线⽹卡），选择“属性”，点击“共 享”，勾选“允许其他⽹络⽤户通过此计算机的 Internet连接来连接”选项，在下拉菜单中选择刚才建⽴ 的虚拟⽹络（⼀般是“⽆线⽹络2”），确定。（如果找不到这个选项，请重新启动电脑，然后才有可能 找到该选项）

⾄此，你利⽤⽆线⽹卡建⽴的⽆线 AP 已经完成，打开⼿机的 WIFI 功能，搜索⽆线⽹络，找到步骤⼆ 中的⽆线名称，并输⼊步骤⼆中的密码，连接成功后就可以上⽹了。 补充：如果要取消⽆线⽹卡的 AP 模式，请直接重启电脑即可。

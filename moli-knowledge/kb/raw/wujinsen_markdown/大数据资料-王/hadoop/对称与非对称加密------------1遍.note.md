# 1、⾮对称加密： （⽤颜⾊形状区分不同的公钥私钥）

- 1、 把私钥⽐喻成钥匙，钥匙的底部是⼀个凹下去的刚戳。
- 2、 把公钥⽐喻成锁头，与对⽤私钥相对应。
- 3、 明⽂⽤私钥签名，⽐喻成⽤私钥底部的戳盖了个凹下去的刚戳（类似于咱们玩游戏中，密码⼭洞中 凹下去的那种锁），签名后，你⼿头可能有不同的公钥，找到能放进去的对应公钥，不仅可以打开密 ⽂⽂件，还可以知道是哪个私钥加的密。
- 4、 当明⽂⽤公钥加密后，⽤其他公钥私钥是打不开的，因为其他公钥也是⼀把锁头，其他私钥是不同 的钥匙，但是⽤对应的私钥就可以解开。

Linux ⽤户（user）和⽤户组（group）管理概述

、理解Linux的单⽤户多任务，多⽤户多任务概念；

Linux 是⼀个多⽤户、多任务的操作系统；我们应该了解单⽤户多任务和多⽤户多任务的概念；

- 1、Linux 的单⽤户多任务；

单⽤户多任务；⽐如我们以beinan 登录系统，进⼊系统后，我要打开gedit 来写⽂档，但在写⽂档的 过程中，我感觉少点⾳乐，所以⼜打开xmms 来点⾳乐；当然听点⾳乐还不⾏，MSN 还得打开，想 知道⼏个弟兄现在正在做什么，这样⼀样，我在⽤beinan ⽤户登录时，执⾏了gedit 、xmms以及 msn等，当然还有输⼊法fcitx ；这样说来就有点简单了，⼀个beinan⽤户，为了完成⼯作，执⾏了 ⼏个任务；当然beinan这个⽤户，其它的⼈还能以远程登录过来，也能做其它的⼯作。

- 2、Linux 的多⽤户、多任务； 有时可能是很多⽤户同时⽤同⼀个系统，但并不所有的⽤户都⼀定都要做同⼀件事，所以这就有多⽤ 户多任务之说； 举个例⼦，⽐如LinuxSir.Org 服务器，上⾯有FTP ⽤户、系统管理员、web ⽤户、常规普通⽤户 等，在同⼀时刻，可能有的弟兄正在访问论坛；有的可能在上传软件包管理⼦站，⽐如luma 或 Yuking 兄在管理他们的主⻚系统和FTP ；在与此同时，可能还会有系统管理员在维护系统；浏览主⻚ 的⽤的是nobody ⽤户，⼤家都⽤同⼀个，⽽上传软件包⽤的是FTP⽤户；管理员的对系统的维护或查 看，可能⽤的是普通帐号或超级权限root帐号；不同⽤户所具有的权限也不同，要完成不同的任务得 需要不同的⽤户，也可以说不同的⽤户，可能完成的⼯作也不⼀样； 值得注意的是：多⽤户多任务并不是⼤家同时挤到⼀接在⼀台机器的的键盘和显示器前来操作机器， 多⽤户可能通过远程登录来进⾏，⽐如对服务器的远程控制，只要有⽤户权限任何⼈都是可以上去操 作或访问的；
- 3、⽤户的⻆⾊区分； ⽤户在系统中是分⻆⾊的，在Linux 系统中，由于⻆⾊不同，权限和所完成的任务也不同；值得注意 的是⽤户的⻆⾊是通过UID和识别的，特别是UID；在系统管理中，系统管理员⼀定要坚守UID 唯⼀ 的特性； root ⽤户：系统唯⼀，是真实的，可以登录系统，可以操作系统任何⽂件和命令，拥有最⾼权限； 虚拟⽤户：这类⽤户也被称之为伪⽤户或假⽤户，与真实⽤户区分开来，这类⽤户不具有登录系统的 能⼒，但却是系统运⾏不可缺少的⽤户，⽐如bin、daemon、adm、ftp、mail等；这类⽤户都系统 ⾃身拥有的，⽽⾮后来添加的，当然我们也可以添加虚拟⽤户； 普通真实⽤户：这类⽤户能登录系统，但只能操作⾃⼰家⽬录的内容；权限有限；这类⽤户都是系统 管理员⾃⾏添加的；


- 4、多⽤户操作系统的安全； 多⽤户系统从事实来说对系统管理更为⽅便。从安全⻆度来说，多⽤户管理的系统更为安全，⽐如 beinan⽤户下的某个⽂件不想让其它⽤户看到，只是设置⼀下⽂件的权限，只有beinan⼀个⽤户可读 可写可编辑就⾏了，这样⼀来只有beinan⼀个⽤户可以对其私有⽂件进⾏操作，Linux 在多⽤户下表 现最佳，Linux能很好的保护每个⽤户的安全，但我们也得学会Linux 才是，再安全的系统，如果没有 安全意识的管理员或管理技术，这样的系统也不是安全的。 从服务器⻆度来说，多⽤户的下的系统安全性也是最为重要的，我们常⽤的Windows 操作系统，它在 系纺权限管理的能⼒只能说是⼀般般，根本没有没有办法和Linux或Unix 类系统相⽐；


⼆、⽤户(user）和⽤户组（group）概念；

- 1、⽤户（user）的概念；

通过前⾯对Linux 多⽤户的理解，我们明⽩Linux 是真正意义上的多⽤户操作系统，所以我们能在 Linux系统中建若⼲⽤户（user）。⽐如我们的同事想⽤我的计算机，但我不想让他⽤我的⽤户名登 录，因为我的⽤户名下有不想让别⼈看到的资料和信息（也就是隐私内容）这时我就可以给他建⼀个 新的⽤户名，让他⽤我所开的⽤户名去折腾，这从计算机安全⻆度来说是符合操作规则的； 当然⽤户（user）的概念理解还不仅仅于此，在Linux系统中还有⼀些⽤户是⽤来完成特定任务的，⽐ 如nobody和ftp 等，我们访问LinuxSir.Org 的⽹⻚程序，就是nobody⽤户；我们匿名访问ftp 时， 会⽤到⽤户ftp或nobody ；如果您想了解Linux系统的⼀些帐号，请查看 /etc/passwd ；

- 2、⽤户组（group）的概念；


⽤户组（group）就是具有相同特征的⽤户（user）的集合体；⽐如有时我们要让多个⽤户具有相同 的权限，⽐如查看、修改某⼀⽂件或执⾏某个命令，这时我们需要⽤户组，我们把⽤户都定义到同⼀ ⽤户组，我们通过修改⽂件或⽬录的权限，让⽤户组具有⼀定的操作权限，这样⽤户组下的⽤户对该 ⽂件或⽬录都具有相同的权限，这是我们通过定义组和修改⽂件的权限来实现的； 举例：我们为了让⼀些⽤户有权限查看某⼀⽂档，⽐如是⼀个时间表，⽽编写时间表的⼈要具有读写 执⾏的权限，我们想让⼀些⽤户知道这个时间表的内容，⽽不让他们修改，所以我们可以把这些⽤户 都划到⼀个组，然后来修改这个⽂件的权限，让⽤户组可读，这样⽤户组下⾯的每个⽤户都是可读 的；

⽤户和⽤户组的对应关系是：⼀对⼀、多对⼀、⼀对多或多对多；

⼀对⼀：某个⽤户可以是某个组的唯⼀成员；

多对⼀：多个⽤户可以是某个唯⼀的组的成员，不归属其它⽤户组；⽐如beinan和linuxsir两个⽤户 只归属于beinan⽤户组； ⼀对多：某个⽤户可以是多个⽤户组的成员；⽐如beinan可以是root组成员，也可以是linuxsir⽤户 组成员，还可以是adm⽤户组成员； 多对多：多个⽤户对应多个⽤户组，并且⼏个⽤户可以是归属相同的组；其实多对多的关系是前⾯三 条的扩展；理解了上⾯的三条，这条也能理解；

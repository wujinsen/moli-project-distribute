- 13课


1.〜なしで

含义

表示本来应该有的东⻄却没有，“没有 …就 …”，“缺少 …就 …”。 带有“不可思议/不像话”的语⽓。

例句：

おせちなしで正⽉を迎えることなど、昔は考えられなかったことだ。

→ 没有御节就迎接新年，在过去是根本⽆法想象的事。 お年寄りたちの助⾔なしで、伝統⾏事を守り続けるるのは無理だ。

→ 没有⽼年⼈的建议，要⼀直守住传统活动是不可能的。

# ✅ 2.〜ことか

含义

表示程度之深，“多么 …啊”“不知道 …多少次/多么 …”。 常与情绪・感叹词搭配，如：どれほど、どんなに、何度、何回、どれだけ。

例句：

⼦供相⼿のような⼝のきき⽅をされて、何度思い出しても腹が⽴ってしょうがない。 （这⾥是「〜てしょうがない」，但前例句说明⽤法） ベッドに何かいたのか、今⽇は朝から体が痒くてしょうがない。

→ 不知道床上是不是有什么东⻄，今天从早上开始身体痒得不得了。 雪深い⼭国で、いかに年を取った両親の⽣活に困っているのではと、最近気が気でならない。 （此句是「気が気でならない」，但前句⽤于说明某种⼼情）

# ✅ 3.⽂字通り（もじどおり）

含义

“从字⾯意义来看就是那个意思”，⽤于强调：

不是⽐喻，⽽是货真价实、字⾯上的意思。 常误⽤为“⼤家都知道 …”，需注意。

例句：

両親は、⽂字通り、朝から晩まで汗⽔たらして働いて、私たちを育ててくれた。

→ ⽗⺟真的是从早到晚挥汗如⾬地⼯作，把我们养⼤。 ⼤平洋は⽂字通り、広くて⼤きくて、どこを⾒ても⽔平線しか⾒えなかった。

→ 太平洋真的是宽⼴巨⼤，⽆论看哪⾥都只能看到⽔平线。

# ✅ 4.⽴ち寄る（たちよる）

含义

“顺便去⼀下某地”“中途停留”，常指：

没有特别理由

刚好路过

临时进去⼀下

例句：

帰郷の折にたまたま⽴ち寄った⼩学校は、校舎が新しくなり、すっかり昔の⾯影をなくしていた。

→ 回⽼家时偶然顺便去了⼀下那所⼩学，校舍已经变新了，完全看不出过去的样⼦。 ⽗が体調を崩したと聞いて、⽴ち寄った実家に⼀⽬ぼっり驚いて世話をした。

→ 听说⽗亲身体不好，顺道回⽼家，⼀看之下吃惊得⽴刻开始照顾他。

# ✅ 5.しょせん（所詮）

含义

“归根到底”“最终不过是 …” 带有消极评价的语⽓。 表示：

由现在状况推断，最终肯定不会是什么好的结果。

例句：

仕事再開をかけると⾔っても、しょせん定年が来れば『ご苦労様でした』と⾔って追われることに なるのだ。

→ 即使说要赌上⼯作继续⼲下去，但终究退休⼀来，也只会被说⼀句“⾟苦了”然后被迫离开。 いくら好きだと⾔っても、社⻑の娘じゃ、平社員にはしょせん叶わぬ願いでしかない。

→ ⽆论多喜欢，对社⻓的⼥⼉来说，对于普通员⼯终究只是⽆法实现的愿望。

# ✅ 6.なりわい（⽣業）

含义

写作「⽣業」，原意是“为了⽣存的职业”。 现代⽇语表示：

⼀⽣靠它维持⽣计的事业或⼯作。

例句：

（原⽂后没给例句，我补⼀个常⻅例句） 漁はこの町の⼈々のなりわいだ。

→ 捕⻥是这个⼩镇居⺠赖以为⽣的职业。

# 14课 1.た拍⼦に（たひょうしに）

＝ 正好在 …的时候／就在某个动作瞬间 …（意外性）

➡ 多⽤于“⽆意识”“突然发⽣”“不好的事”。

- ✔ ⽤法

- ✔ 例句


「動詞た形＋拍⼦に」

⽴ち上がった拍⼦に、腰に激しい痛みが⾛った。

→ 刚站起来时，腰突然⼀阵剧痛。

笑った拍⼦に、変な声が出た。

→ ⼀笑的时候突然发出了奇怪的声⾳。

# ✅ 2.に限って（にかぎって）

有三个主流意思，注意区分！

- (1)偏偏在 …的时候（不幸运）

✔ 例

⾬なんか降らないと思っていた⽇に限って、⼤⾬が降る。

→ 偏偏在我以为不会下⾬的那天就下⼤⾬。

- (2)只有 …是特别的情况（强烈信赖）

✔ 例

彼に限って、そんなことをするはずがない。

→ 只有他不可能做那种事。（我相信他）

- (3)限定：仅限于 …（正式书⾯）


➡ 和中⽂“偏偏”“就”很像

➡ 常与负⾯事件⼀起出现

➡ 说某⼈“不会做坏事”，⼀种“我相信他”的语感

✔ 例

この値引きは会員に限って適⽤されます。

→ 这个折扣只限会员。

# ✅ 3.ても〜きれない

＝ 怎么 …也不够／再 …也⽆法彻底 …

➡ 后⾯常接“感謝する／謝る／数える／⾔う”等含量⼤、⽆法完全做到的动作。

- ✔ 构成

- ✔ 例句


「Vて＋も＋Vきれない」

助けてくれたあなたには、感謝してもしきれない。

→ 对你的帮助，再怎么感谢也不够。

⼼配してもしきれない。 → 怎么担⼼也担⼼不完。

# ✅ 4.〜次第（しだい）

两个主要意思：

## (1)⼀ …就 …（顺序紧接）

➡「Vます形＋次第」

➡ 表示“事情完成后⻢上进⾏下⼀步”

✔ 例句

準備ができ次第、出発します。

→ 准备⼀好就出发。

⾬がやみ次第、試合を再開します。

→ ⾬⼀停就继续⽐赛。

## (2)取决于 …／要看 …

➡ 名词＋次第（しだい）

➡ 表示结果因“状况／程度”⽽变化

✔ 例句

成功するかどうかは、努⼒次第だ。

→ 成不成功取决于努⼒。

値段は数量次第で決まります。

→ 价格根据数量⽽定。

〜次第② N …

- 15课


# ①たが最後（たがさいご）

接续：Vた形 + が最後 含义：⼀旦 …就（彻底） …；⼀ …就（必定产⽣⽆法挽回的状态）

➡ ⼀种 强烈不可逆 的语⽓。

### 例句

彼はゲームをし始めたが最後、夜中までやめようとしない。 ⼀旦他开始玩游戏就停不下来。

その薬を飲んだが最後、⼀⽇中眠くなるよ。 ⼀旦吃了那个药，就会⼀整天犯困。

# ②はおろか

接续：N（名词）＋はおろか 含义：别说 …，就连 …也（不） …

➡ 前项是更容易的，后项是更困难（却也不…／却也…）。

### 例句

彼は漢字はおろか、ひらがなさえ読めない。 他别说汉字了，连平假名都不会读。

忙しすぎて旅⾏はおろか、休みの⽇に家でゆっくりする時間もない。 忙得连旅⾏就别提了，连在家放松的时间都没有。

# ③（られる）ものなら

接续：可能形 + ものなら 含义：如果（能） …的话（⼏乎不可能/假设性很强）

➡ ⽤于表达现实中 难以实现的愿望或假设。

### 例句

戻れるものなら、学⽣時代に戻りたい。 如果能回去的话，我想回到学⽣时代。

⾏けるものなら、宇宙に⾏ってみたい。 要是能去的话，我想去宇宙看看。

# ④てでも

接续：Vて形 + でも 含义：就算要 …也要 …（不惜⼿段）

➡ 表示为了达成⽬的，即使⽤极端⼿段也要去做。

### 例句

早く会いたくて、徹夜してでも会いに⾏くつもりだ。 想早点⻅到你，就算熬夜也要去。

お⾦を借りてでも、この機会を逃したくない。 就算借钱，也不想错过这个机会。

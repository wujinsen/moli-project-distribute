# 1.禁じ得ない（きんじえなかった）

意味（中⽂）

情不⾃禁；不由得；忍不住 … ⽤于表达某种强烈的情感⽆法抑制，多⽤于正式书⾯语。

接续

名詞＋を禁じ得ない

例句

彼の話を聞いて、涙を禁じ得なかった。 听了他的故事，我情不⾃禁流下了眼泪。

不公平な扱いに怒りを禁じ得ない。 受到不公平对待，不由得⽣⽓。

その光景を⾒て、悲しみを禁じ得なかった。 看到那⼀幕，不由得悲伤。

# ✅ 2.ものともしない

意味（中⽂）

不把 …当回事；毫不在意；⽆视困难、危险也不怕 带有“强⼤、勇敢、不顾⻛险”的感觉。

接续

名詞＋をものともしない（で） …

例句

彼は周囲の反対をものともしないで、留学を決めた。

他完全不把周围的反对当回事，决定去留学。 若い選⼿は怪我をものともしない活躍を⾒せた。

年轻选⼿表现得仿佛完全不把伤病当回事。

困難をものともしないで前に進む彼の姿に感動した。 他不惧困难继续前进的样⼦令⼈感动。

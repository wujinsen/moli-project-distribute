- 1. ps 简介 ps 命令就是最根本相应情况下也是相当强⼤地进程查看命令.运⽤该命令可以确定有哪些进程正在运⾏ 和运⾏地状态、 进程 是否结束、进程有没有僵死、哪些进程占⽤了过多地资源等等.总之⼤部分信息均 为可以通过执⾏该命令得到地.

- 2. ps 命令及其参数 ps 命令最经常使⽤地还是⽤于监控后台进程地⼯作情况,因为后台进程是不和屏幕键盘这些标准输⼊/ 输出设 备进⾏通信地,所以如果需要检测其情况,便可以运⽤ ps 命令了. 该命令语法格式如下： ps [选项]


- -e 显示所有进程,环境变量

- -f 全格式

- -h 不显示标题

- -l ⻓格式

- -w 宽输出 a 显示终端上地所有进程,包括其他⽤户地进程 r 只显示正在运⾏地进程 x


显示没有控制终端地进程 O[+|-] k1 [,[+|-] k2 [,…] 根据 SHORT KEYS、k1、k2 中快捷键指定地多级排序顺序显示进程列表. 对于 ps 地不同格式都存在着默认地顺序指定.这些默认顺序可以被⽤户地指定所覆盖.在这⾥⾯“+”字符 是可选地,“-” 字符是倒转指定键地⽅向. pids 只列出进程标识符,之间运⽤逗号分隔.该进程列表必须在命令⾏参数地最后⼀个选项后⾯紧接着给 出,中间不能插⼊ 空格.⽐如：ps -f1,4,5. 以下介绍⻓命令⾏选项,这些选项都运⽤“-”开头：

-sort X[+|-] key [,[+|-] key [,…] 从 SORT KEYS 段中选⼀个多字⺟键.“+”字符是可选地,因为默认地⽅ 向就是按 数字升序或者词典顺序.⽐如： ps -jax -sort=uid,-pid,+pid.

- G 移到⽂件的最后⼀⾏

- nG 移到⽂件的第n⾏


- w 移到下⼀个字的开头


- W 移到下⼀个字的开头，忽略标点符号


b 移到前⼀个字的开头

- M 移到屏幕的中间⼀⾏


- H 移到屏幕的第⼀⾏

E 移到下⼀个字的结尾，忽略标点符号

( 移到句⼦的开头

) 移到句⼦的结尾

{ 移到段落的开头

} 移到下⼀个段落的开头

0或| 移到当前⾏的第⼀列

- n| 移到当前⾏的第n列

^ 移到当前⾏的第⼀个⾮空字符

$ 移到当前⾏的最后⼀个字符

+或return 移到下⼀⾏的第⼀个字符

在vi中删除⽂本

命令 删除操作

- x 删除光标处的字符，可以在x前加上需要删除的字符数⽬


nx 从当前光标处往后删除n个字符

- X 删除光标前的字符，可以在X前加上需要删除的字符数⽬

ndw 从当前光标处往后删除n个字

- ^w 插⼊时，删除前⾯的字


修改vi⽂本

每个命令前⾯的数字表⽰该命令重复的次数

命令 替换操作

rchar ⽤char替换当前字符

:g/text/command 在所有包含text的⾏运⾏command所表⽰的命令

:v/text/command 在所有不包含text的⾏运⾏command所表⽰的命令

- 1.编辑模式: 插⼊/替换 （按INSERT键切换）

- 2.[ESC] 指令模式

- 3.输⼊模式 将在指令模式下输⼊ a


新增（a,A）

a:从光标所在位置后⾯开始新增资料，光标后的资料随新增资料向后移动。

A:从光标所在列最后⾯的地⽅开始新增资料。

插⼊（i,I）

i:从光标所在位置前⾯开始插⼊资料，光标后的资料随新增资料向后移动。

I:从光标所在列的第⼀个⾮空⽩字元前⾯开始插⼊资料。

开始（o,O）

o:在光标所在列下新增⼀列并进⼊输⼊模式。

O:在光标所在列上⽅新增⼀列并进⼊输⼊模式。

- 4.存盘/退出

[ESC] :wq //存盘退出

:w! //存盘继续

:q //退出 （源⽂件未被编辑过可⽤）

:q! //强制退出

- 5.删除与改修

[ESC] x //删除光标所在字符

dd //删除光标所在列。

- r //修改光标所在字元，r后接着要修正的字符。

- R //进⼊取替换状态。

s //删除光标所在字元，并进⼊输⼊模式。

- S //删除光标所在的列，并进⼊输⼊模式。




- 6.恢复

# 生产 / 预发环境检查表

> 配合 [[v1发布Runbook]] 使用

## 1. 基础设施

MySQL 8 utf8mb4 · Redis 6+ · Nacos 2.x 命名空间隔离 · NTP 时钟同步

## 2. 网络与端口

| 服务 | 端口 | 对外 |
|------|------|------|
| gateway | 21000 | ✅ 唯一 HTTP 入口 |
| user-center | 8888 | ❌ 内网 |
| order | 8087 | ❌ 内网 |
| knowledge | 8090 | ❌ 内网 |
| bi | 1128 | ❌ 内网 |

## 3. 配置必查

- 全服务 `spring.redis.database` **一致**
- user-center：`captcha.enabled` 生产建议 true
- order：`moli.seckill.load-test-mode` **生产 false**
- knowledge：`kb.llm`、`kb.ingest.enabled`、MinIO
- gateway：CORS / HTTPS 在 Nginx/LB

## 4. 安全

- 改默认演示账号密码
- Swagger 生产限制暴露
- `/seckill/admin/init` 关闭 loadtest
- LLM Key 不在 Git

## 5. 数据

- 迁移脚本版本与 tag 一致（[[SQL迁移顺序]]）
- 发布前 DB 备份
- 计划 wiki Sync

## 6. 签核

全部 P0 勾选后执行冒烟清单。

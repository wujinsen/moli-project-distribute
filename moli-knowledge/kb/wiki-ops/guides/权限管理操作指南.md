# 权限管理操作指南

面向「我怎么管用户、建角色、授权」的操作指导。模型见 [[rbac-权限模型]]，接口都在 [[用户中心]]（经网关 `/UserCenter/...`，需带 token，见 [[登录与鉴权指南]]）。

## 典型流程：给新员工开通权限

```
1. 建部门（可选）   POST /dept
2. 建用户          POST /user           （分配到部门）
3. 建角色          POST /role
4. 给角色授权      PUT  /role           （带 menuIds + actionCodes）
5. 给用户分配角色   PUT  /user/insertUserRole
6. （多系统门户）   PUT  /user/insertUserSystem
```

## 常用接口

### 用户 `/user`

| 操作 | 接口 | 所需权限 |
|------|------|----------|
| 列表 | `GET /user/list` | `system:user:list` |
| 新增 | `POST /user` | `system:user:add` |
| 改他人 | `PUT /user` | `system:user:edit` |
| 删除 | `DELETE /user/{userIds}` | `system:user:remove` |
| 启停用 | `PUT /user/changeStatus` | `system:user:edit` |
| 分配角色 | `PUT /user/insertUserRole` | `system:user:assignRole` |
| 重置密码 | `PUT /user/resetPassword` | `system:user:resetPwd` |
| 改本人密码 | `PUT /user/changePassword` | 登录即可 |

### 角色 `/role`

| 操作 | 接口 | 所需权限 |
|------|------|----------|
| 列表 | `GET /role/list` | `system:role:list` |
| 新增 | `POST /role` | `system:role:add` |
| 授权 | `PUT /role`（带 `menuIds`/`actionCodes`） | `system:role:assignPerm` |
| 查授权回显 | `GET /role/{id}/auth` | `system:role:list` |

### 菜单 `/menu` / 部门 `/dept` / 动作 `/action`

- 菜单 CRUD（`system:menu:*`）、当前用户路由 `GET /menu/getRouters`（登录即可）。
- 部门树 CRUD（`system:dept:*`，删除级联子部门）。
- 细粒度动作码 CRUD（`/action`），对应 [[rbac-权限模型]] 的 `sys_action` 双轨。

## 注意事项

- **超管** `superadmin`/`admin` 拥有 `*:*:*`，不受单条 perms 限制。
- **授权改动后**：清了 `shiro:cache` 缓存才生效，用户可能需下次授权检查或重新登录。
- **停用用户即时失效**：`AuthenticationFilter` 每次请求都校验账号状态。
- 完整 ~70 接口与权限矩阵见 [`docs/api/user-center-api-map.md`](../../../../docs/api/user-center-api-map.md)。

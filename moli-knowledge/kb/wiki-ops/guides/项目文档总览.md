# 项目文档总览（moli-ops-manual）

> **本空间**（`moli-ops-manual`）汇总 **已处理完毕、可运维/联调使用** 的项目文档入口。  
> **工程契约权威**仍在仓库 `docs/`；本 wiki 为 **浏览 + 操作索引**，正文以 `sources` 链到 Git 路径为准。  
> **Web 端链接规则**：页内互跳用 `[[slug]]`；工程文件用反引号路径（如 `` `docs/product/foo.md` ``），在 IDE/Cursor 中打开——**不要用** `../../../../` 相对 markdown 链接。
